# Manual Test — US-045: Nueve FunctionTools geoespaciales con schemas Pydantic

Verificacion de las 9 tools del agente (`google-genai` `FunctionDeclaration`), cada una con
schema Pydantic `ToolInput`/`ToolOutput`, `structlog` y RLS por `session_id`. Lo automatizable
esta cubierto por `tests/ml/agent/` (53 tests, cobertura `ml.agent` ~86%). Los flujos que
requieren **Postgres + PostGIS con datos reales de sesion** se marcan como validacion manual.

> Commit: `c0d237e feat(E7): US-045 nueve FunctionTools geoespaciales con schemas Pydantic`.
> Handoff: [docs/us-handoff/us-045.md](../us-handoff/us-045.md) · Plan v8 §US-045.

> real y (para classify) el modelo XGBoost cacheado. Validar en demo localhost.

| Flujo | Pasos | Resultado esperado | Estado |
|-------|-------|--------------------|--------|
| `list_parcels` real | levantar Postgres+PostGIS con parcelas de `session_id=X`; invocar la tool | devuelve solo parcelas de X | [ ] **manual** |
| RLS cross-tenant real | invocar `list_parcels` con `session_id=Y` sobre datos de X | lista vacia (no fuga) | [ ] **manual** |
| `classify_new_parcel` real | parcela con `alphaearth_embedding` 64-dim -> XGBoost | posterior 18-clase coherente | [ ] **manual / GPU-opcional** |
| `classify` sin embedding | parcela sin embedding persistido | sentinel `needs_gee_sampling` (no excepcion) | [ ] **manual** |
| `explain_prediction` real | parcela con fenologia -> descriptor Wen 2025 | TEXTO Be My Eyes, cifras trazables a tool calls | [ ] **manual** |
