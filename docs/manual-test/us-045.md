# Manual Test — US-045: Nueve FunctionTools geoespaciales

Verificacion de las 9 FunctionTools del agente (5 sync demo + 4 deferred) sobre `ml/agent/`,
con contratos Pydantic v2, SQL 100% parametrizado y aislamiento por `session_id` (defensa en
profundidad; la RLS policy es EPIC 11). Lo automatizable esta cubierto por `tests/ml/agent/`;
los flujos que requieren Postgres+PostGIS con datos reales de sesion siguen `[ ]` legitimos
(no son codigo incompleto, son no-automatizables en CI). Fuente unica de QA: el handoff
embebido ([docs/us-handoff/us-045.md](../us-handoff/us-045.md)).

> US-045 cubre el criterio FunctionTools del agente (EPIC 7) — 9 tools geoespaciales con

## MT-6 — Pendientes manuales y caveats honestos

No automatizable en CI: requiere Postgres+PostGIS con parcelas de una sesion real y (para
classify) el modelo XGBoost cacheado. Validar en demo localhost.

| Item | Nota | Estado |
|------|------|--------|
| `list_parcels` real | Postgres+PostGIS con parcelas de `session_id=X` -> solo parcelas de X | [ ] manual (no CI) |
| RLS cross-tenant real | `list_parcels(session=Y)` sobre datos de X -> vacio | [ ] manual (no CI) |
| `classify_new_parcel` real | parcela con embedding 64-dim -> XGBoost -> posterior coherente | [ ] manual / GPU-opcional |
| `classify` sin embedding | parcela sin embedding -> sentinel `needs_gee_sampling` (no excepcion) | [ ] manual |

| `compare_models` con `parcel_id` plano | no matchea ids compuestos OOF (`patch_local`); camino vacio honesto cubierto | [x] documentado (caveat) |
