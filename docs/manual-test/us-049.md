# Manual Test — US-049: Evaluacion del copiloto (AgroMind + GeoAnalystBench)

Verificacion del harness de evaluacion **eval-only** (NUNCA fine-tune; AgroMind sin train split =
leakage, ADR-009/011) de las 3 variantes del reasoner: **Gemini 3.5-flash** (cloud, multimodal),
**Qwen3-30B-A3B** (on-prem llama.cpp, solo texto) y **Gemma 4 26B-A4B MoE** (on-prem Ollama,
multimodal, referencia). Lo automatizable esta en `tests/ml/eval/` (46 tests: agent_bench 10,
agent_metrics 36). La **corrida real** (500 AgroMind + 50 GeoAnalystBench, 1 seed) es un flujo
**GPU/manual** con endpoints on-prem vivos + budget de API.

## Caveats honestos

| Item | Nota | Estado |
|------|------|--------|
| Subset AgroMind casi todo multimodal | 494/500 multimodal -> Qwen (text-only) solo evalua 6; para eval real de Qwen conviene ampliar `make_subset` con filtro `is_multimodal=False` | [x] documentado |
| LLM-as-judge = costo extra | la hallucination_rate usa un juez (Gemini/vLLM) -> dobla las llamadas LLM por item | [x] documentado |
| codebleu aproximado | BLEU n-gram + keyword overlap (sin AST data-flow); documentado | [x] documentado |
| bertscore_f1 = proxy | sentence-transformers, documentado como proxy semantico | [x] documentado |
| Gemini 3.5-flash sustituye a 2.5-pro | decision del usuario (menor costo); el harness es agnostico al id | [x] documentado |
