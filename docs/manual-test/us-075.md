## 5. Remapeo a HCAT (crosswalk US-074) + compatibilidad dataloader denso

- **Adapter**: `MACRO_GROUP_TO_ID` se deriva de `MACRO_HCAT_GROUPS` (US-074, `ml/data/hcat_crosswalk.py`),
  excluyendo `void`; background / fuera-de-nomenclatura -> `ignore_index=255`. FAO-ICC -> macro via
  `FAO_ICC_TO_MACRO` + `build_fao_icc_lut`. 10 clases macro.
- **Crosswalk consistente (verificado linea a linea)**: `_SEMANTIC18_TO_MACRO_NAME` en
  `ml/train/finetune_sen4agrinet.py` (proyeccion 18->macro del modelo Francia) coincide EXACTAMENTE
  con `_HCAT_MACRO_BY_ID` de `ml/eval/class_remap.py` (el campo macro tras `|`): id 0->grassland,
  4/6->oilseed_industrial, 7->vineyard, 8->sugar_beet, 11->vegetables, 12->potato, 13->legumes_fodder,
  14->soybean, 15->orchard, resto->cereals. `build_semantic18_to_macro_lut` tiene un guard que
  levanta `KeyError` si un id mapea a un macro ausente de `MACRO_GROUP_TO_ID` (anti-drift).
- **`macro_groups` del JSON** == `MACRO_HCAT_GROUPS` menos `void` (10 grupos, mismo orden). Apples-to-apples.
- **Compatibilidad dataloader denso**: el adapter emite el contrato PASTIS `(T,10,128,128) float32` /
  `(128,128) int64`, identico a `PASTISSegmentationDataset`. El finetune lo consume con
  `build_tsvit(num_classes=10, n_timesteps=10, in_channels=10)` sin reescribir el dataloader; el
  encoder Francia carga con `load_state_dict(strict=False)` (head 18 reinit a 10; encoder transferido).

VERDE.
