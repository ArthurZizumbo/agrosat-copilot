## MT-5 — Caveats honestos (blockers documentados)

| Item | Nota | Estado |
|------|------|--------|
| GPU util / OOM | sin `dcgm-exporter` + Prometheus en el entorno -> panel/alerta plantilla, sin datos inventados | [x] documentado (B1) |
| Alertas a canal real | requieren proyecto desplegado + Alertmanager / alert policy | [x] documentado (B2) |
| Cloud Run scale-to-zero | `min_instances=0` no scrapeable por pull -> push gateway / Cloud Monitoring | [x] documentado (B3, `infrastructure/grafana/README.md`) |
| Paneles de chat | latencia p95 / tokens / modelo activo / tool-call success -> trafico `/chat` real en US-065; no se fabrica trafico | [x] documentado (B4) |
| `CONTENT_TYPE_LATEST` 1.0.0 | con prometheus-client 0.25.0 es `version=1.0.0`; test asserta el simbolo de la libreria | [x] documentado (B5) |
| `Duplicated timeseries` | resuelto con `DEFAULT_REGISTRY` dedicado + `get_default_metrics()` singleton (re-instanciar la app ya no rompe 13 tests de chat) | [x] verificado |
