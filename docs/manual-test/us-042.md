Verificacion del experimento incremental E-b sobre PASTIS-R real (fold-5 held-out): extender E-a (la fusion
dual-head de US-041) anadiendo el embedding **AlphaEarth** (XGBoost a nivel parcela) como miembro del stacking,
para medir HONESTAMENTE si el FM tabular aporta senal complementaria sobre el camino denso + contrastivo.

La narrativa esta en `notebooks/final_model/Avance5.Equipo17.ipynb` (celdas 9-11).

**Lectura honesta**: anadir AlphaEarth via stacking recupera **+15,6 puntos** sobre la E-a degradada (0,2694 ->
0,3395) — el meta-modelo aprende a apoyarse en el miembro tabular donde la base denso-fusionada falla. Pero E-b
(0,3395) queda **a 40,8 puntos** del Stacking US-040 (0,747) porque hereda la base E-a rota (fusion ingenua de
US-041). **El champion NO es E-b.** La leccion (notebook celda 11): la senal complementaria solo paga cuando la
base es complementaria; apilar sobre una base corrupta no la arregla. La via correcta (Stacking sobre los miembros
densos de US-040 + FarSLIP via stacking) se valida en US-043.
