## 1. CRUD `/aois` (AC-1, AC-6)

### Crear (POST -> 201, GeoJSON Feature con area_ha)

```bash
curl -s -X POST http://localhost:8000/aois \
  -H "X-Session-ID: $SESSION_A" \
  -H "Content-Type: application/json" \
  -d '{
        "geometry": {
          "type": "Polygon",
          "coordinates": [[[11.0,43.0],[11.1,43.0],[11.1,43.1],[11.0,43.1],[11.0,43.0]]]
        },
        "label": "parcela-demo"
      }'
```

Respuesta esperada (201):

```json
{
  "type": "Feature",
  "id": 1,
  "geometry": {"type": "Polygon", "coordinates": [[[11.0,43.0], ...]]},
  "properties": {"label": "parcela-demo", "area_ha": 86.7, "created_at": "..."}
}
```

`area_ha` se calcula geodesicamente en SQL (`ST_Area(geom::geography)/10000`); el
`session_id` NO se acepta en el body (`extra=forbid` + RLS hook lo inyecta desde
`current_setting('app.current_session')`).

### Listar (GET -> 200, solo las de la sesion)

```bash
curl -s http://localhost:8000/aois -H "X-Session-ID: $SESSION_A"
# -> FeatureCollection con la AOI de A
```

### Obtener por id / borrar (GET 200, DELETE 204, luego 404)

```bash
curl -s http://localhost:8000/aois/1 -H "X-Session-ID: $SESSION_A"            # 200
curl -s -o /dev/null -w "%{http_code}\n" -X DELETE \
  http://localhost:8000/aois/1 -H "X-Session-ID: $SESSION_A"                  # 204
curl -s -o /dev/null -w "%{http_code}\n" \
  http://localhost:8000/aois/1 -H "X-Session-ID: $SESSION_A"                  # 404
```

### Geometria no-Polygon -> 422 (AC-6)

```bash
curl -s -o /dev/null -w "%{http_code}\n" -X POST http://localhost:8000/aois \
  -H "X-Session-ID: $SESSION_A" -H "Content-Type: application/json" \
  -d '{"geometry": {"type": "Point", "coordinates": [11.0, 43.0]}}'          # 422
```

## 6. `classify_new_parcel` — banderas honestas (AC-7..AC-10)

La tool corre dentro del agente (no es un endpoint HTTP). Validacion CPU directa
sobre OOF cacheados + PASTIS-R local, parcela fold-5 `10003_1103071`:

```python
import asyncio
from ml.agent.tools.classify import run
from ml.agent.schemas import ClassifyParcelInput
from ml.agent.context import ToolContext

# AOI que intersecta la parcela fold-5 sembrada para la sesion
inp = ClassifyParcelInput(
    session_id="11111111-1111-1111-1111-111111111111",
    aoi={"type": "Polygon", "coordinates": [[[ ... ]]]},  # poligono de la parcela
    year=2019,
    use_stacking=True,                 # AC-8: sirve el posterior Stacking-5 si hay OOF
    restrict_to_resolved_classes=True, # AC-7: renormaliza sobre las 9 clases france-9
)
res = asyncio.run(run(inp, ctx))       # ctx con pool + session_id
print(res.crop_class, res.confidence)
print(len(res.class_probabilities), res.class_probabilities)
```

Resultado esperado:

- `use_stacking=True` + OOF presente -> posterior del meta Stacking-5 (logreg
  refit sobre los 5 miembros; el log emite `classify_stacking_used member=stacking-5`).
- `restrict_to_resolved_classes=True` (default) -> `len(class_probabilities)==9`,
  suma ~1.0, nombres reales (Soft winter wheat, Corn, Grapevine, Beet, Meadow,
  Soybeans, Winter barley, Sunflower, Winter rapeseed). Ej.: `Soft winter wheat`
  ~0.999.
- **Las 9 clases france-9** (AC-7/AC-9):
  `{0 Meadow, 1 Soft winter wheat, 2 Corn, 3 Winter barley, 4 Winter rapeseed,`
  `6 Sunflower, 7 Grapevine, 8 Beet, 14 Soybeans}`.

Caminos de degradacion (AC-8, no crashea):

```python
# Parcela fuera del universo fold-5 (poligono nuevo) -> degrada a xgb-alphaearth
#   log: classify_stacking_unavailable reason="parcel not in the fold-5 OOF universe..."
# OOF / PASTIS-R ausentes (dvc no pulled) -> FileNotFoundError capturado -> xgb
#   log: classify_stacking_unavailable reason="fold-5 OOF / PASTIS-R ... not available"
```

Espacio completo (AC-7 OFF):

```python

# -> len(class_probabilities)==18 (posterior semantic18 completo, legacy)
```
