# Manual Test — US-047: Agente factory + stream_response (SDK google-genai local)

Verificacion del factory `create_agent()` + `stream_response()` (loop manual de function calling,
`MAX_TURNS=8`, inyeccion de `session_id` por tool, validacion Pydantic de args) y de la abstraccion
`LLMBackend` dual (Gemini cloud / Qwen vLLM / Gemma Ollama). Lo automatizable esta en
`tests/ml/agent/` (22 tests: agent 13, backends 9) con dobles `FakeBackend`/`FakeGenAIClient`. El
streaming real contra Gemini/Qwen y el `/llm/switch` se marcan como validacion manual (demo).

| `backends.py` 67% cobertura | los paths de streaming real (GeminiBackend `generate_content`/stream, OllamaBackend reasoning) no son unit-testeables sin LLM en vivo; la logica de mapeo si testeada | [x] documentado |

| `GeminiBackend` usa API no-stream para function_calls | + stream para texto (superficie canonica); soporta cliente async y sync (test doubles) | [x] documentado |
