# US-055 — Manual test (TiTiler COG tiling)

Servir tiles PNG NDVI/NDWI on-the-fly desde un COG real (Sentinel-2 farslip
Pianura Padana) y verificar el overlay sobre MapLibre. Sin servidor live: el
backend se levanta con `uvicorn` y se consulta con `curl`/navegador.

## 0. Pre-requisitos

- `.env.local` con `REDIS_URL=redis://localhost:6379/0` (o el de tu stack).
- Redis local arriba (`docker compose up redis`) — opcional: sin Redis el primer
  tile renderiza igual pero la 2a llamada no será `HIT`.
- Un COG real. Se usa el del fixture de test (recorte S2 real + georef EPSG:3857).
  Genera uno con el helper del fixture o usa cualquier COG `EPSG:3857` 4 bandas
  `[B02,B03,B04,B08]`.

> Datos reales (regla Arthur, cero sintético): los píxeles vienen intactos de
> `data/farslip_pairs/pianura_padana/crops/<id>.tif` (4 bandas uint16 256x256,
> reflectancia S2 real, rango ~200..3000) + lat/lon real del `manifest.parquet`
> (`45.0890, 9.6022`, soia). El fixture sólo asigna CRS+transform; **no hay
> `np.random`**.

## 1. Arrancar el backend

```bash
cd backend
poetry run uvicorn backend.app.main:app --reload --port 8000
```

## 2. Construir un COG real (helper del fixture)

```bash
cd backend
poetry run python - <<'PY'
import tempfile
from pathlib import Path
import polars as pl
from backend.app.services import proj_env; proj_env.ensure_proj_data()
import rasterio
from rasterio.transform import from_origin
from rasterio.warp import transform as wt
from rio_cogeo.cogeo import cog_translate
from rio_cogeo.profiles import cog_profiles

d = Path("data/farslip_pairs/pianura_padana")
row = pl.read_parquet(d / "manifest.parquet").row(0, named=True)
with rasterio.open(row["crop_path"]) as s:
    data = s.read()                                   # píxeles S2 reales, intactos
lon, lat = float(row["lon"]), float(row["lat"])       # lat/lon real del manifest
cx, cy = wt("EPSG:4326", "EPSG:3857", [lon], [lat]); res = 10.0
tr = from_origin(cx[0] - 128 * res, cy[0] + 128 * res, res, res)
tmp = Path(tempfile.mkdtemp()); raw = tmp / "raw.tif"; cog = Path("/tmp/real_s2_cog.tif")
prof = dict(driver="GTiff", height=256, width=256, count=4, dtype="uint16",
            crs="EPSG:3857", transform=tr)
with rasterio.open(raw, "w", **prof) as dst: dst.write(data)
cog_translate(raw, cog, cog_profiles.get("deflate"), web_optimized=True, quiet=True)
print("COG:", cog)
PY
```

El COG queda en `/tmp/real_s2_cog.tif` (Linux/WSL) — en Windows usa la ruta que
imprima `tempfile`. El tile que cubre el centro a z=14 es `14/8629/5888`.

## 3. `/cog/tiles` — factory TiTiler literal (AC-2)

NDVI con expresión libre, rescale y colormap (endpoint literal del AC):

```bash
curl -s -o ndvi_cog.png -D - \
  "http://localhost:8000/cog/tiles/WebMercatorQuad/14/8629/5888.png?url=/tmp/real_s2_cog.tif&expression=(b4-b3)/(b4%2Bb3)&rescale=-1,1&colormap_name=rdylgn"
# -> 200, content-type: image/png ; ndvi_cog.png abre como PNG (firma \x89PNG)
```

Metadatos del COG (4 bandas reales):

```bash
curl -s "http://localhost:8000/cog/info?url=/tmp/real_s2_cog.tif" | jq '{count,dtype,crs}'
# -> {"count":4,"dtype":"uint16","crs":"...3857..."}
```

TileJSON para MapLibre:

```bash
curl -s "http://localhost:8000/cog/WebMercatorQuad/tilejson.json?url=/tmp/real_s2_cog.tif&expression=(b4-b3)/(b4%2Bb3)" | jq '.tiles'
```

## 4. `/tiles` — contrato estable US-053 (AC-5, ya no 501)

```bash
curl -s -o ndvi.png -D - \
  "http://localhost:8000/tiles/14/8629/5888.png?url=/tmp/real_s2_cog.tif&index=ndvi"
```

Cabeceras esperadas en la respuesta:

```
HTTP/1.1 200 OK
content-type: image/png
cache-control: public, max-age=900        # AC-4 cache HTTP
x-tile-cache: MISS                          # 2a llamada idéntica -> HIT (AC-3)
```

NDWI:

```bash
curl -s -o ndwi.png "http://localhost:8000/tiles/14/8629/5888.png?url=/tmp/real_s2_cog.tif&index=ndwi"
```

NDMI (4 bandas sin SWIR) — **422 honesto**, no fabrica un índice falso (regla
Arthur):

```bash
curl -s -o /dev/null -w "%{http_code}\n" \
  "http://localhost:8000/tiles/14/8629/5888.png?url=/tmp/real_s2_cog.tif&index=ndmi"
# -> 422
```

## 5. Caché Redis 15 min (AC-3)

```bash
# 1a: MISS (renderiza)
curl -s -D - -o /dev/null "http://localhost:8000/tiles/14/8629/5888.png?url=/tmp/real_s2_cog.tif&index=ndvi" | grep -i x-tile-cache
# x-tile-cache: MISS
# 2a idéntica: HIT (servida de Redis, no toca rio-tiler)
curl -s -D - -o /dev/null "http://localhost:8000/tiles/14/8629/5888.png?url=/tmp/real_s2_cog.tif&index=ndvi" | grep -i x-tile-cache
# x-tile-cache: HIT
```

Clave = `tile:sha256(method|path|sorted(querystring))`, `SETEX` 900 s. Se reusa
`settings.redis_url` (mismo Redis que `rate_limit.py`).

## 6. CORS (AC-4)

```bash
# preflight desde el dominio del frontend
curl -s -D - -o /dev/null -X OPTIONS \
  -H "Origin: http://localhost:3000" \
  -H "Access-Control-Request-Method: GET" \
  "http://localhost:8000/tiles/14/8629/5888.png" | grep -i access-control
# access-control-allow-origin: http://localhost:3000
# access-control-allow-methods: GET, POST, ...
```

## 7. NDVI overlay en MapLibre

Source raster XYZ apuntando al adaptador `/tiles` (TMS WebMercatorQuad
implícito):

```js
map.addSource("ndvi", {
  type: "raster",
  tiles: ["http://localhost:8000/tiles/{z}/{x}/{y}.png?url=/tmp/real_s2_cog.tif&index=ndvi"],
  tileSize: 256,
});
map.addLayer({ id: "ndvi", type: "raster", source: "ndvi", paint: { "raster-opacity": 0.8 } });
```

Para control fino (expresión/rescale/colormap libres) usar el factory:

```
http://localhost:8000/cog/tiles/WebMercatorQuad/{z}/{x}/{y}.png?url=<COG>&expression=(b4-b3)/(b4+b3)&rescale=-1,1&colormap_name=rdylgn
```

| Paso | Esperado | Observado |
|---|---|---|
| `/cog/tiles/.../14/8629/5888.png` NDVI | 200 image/png | OK PNG válido |
| `/cog/info` | count=4, uint16, 3857 | OK |
| `/tiles/.../ndvi` | 200 PNG, no 501 | OK (58 735 bytes) |
| `cache-control` / `x-tile-cache` | `public, max-age=900` / MISS->HIT | OK |
| `index=ndmi` | 422 honesto | OK |
| CORS preflight `localhost:3000` | echo allow-origin + GET | OK |

Nota de seguridad (no AC, ver handoff): el parámetro `url` no restringe
scheme/host — TiTiler hará fetch server-side de cualquier `http(s)://`. En
staging/prod conviene un allowlist (`gs://<GCS_DATA_BUCKET>/...` + COG locales)
para evitar SSRF.
