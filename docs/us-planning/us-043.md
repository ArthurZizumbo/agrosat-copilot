## 2. Arquitectura del sketch (resumen; detalle en ADR-010)

E-c es una **capa de refinamiento estructurado** sobre la salida del mejor ensamble
vigente (E-b / Stacking campeon), no un ensamble nuevo de base learners:

```
SALIDA E-b (probs post-softmax, parcela o densa)
   -> features geo-context (ERA5 clima + SRTM relieve, via GEE zonal)
   -> vecindad de parcela (grafo de adyacencia: borde compartido + k-NN)
   -> capa de refinamiento (UNA de): (A) CRF denso  o  (B) GNN de parcelas
   -> salida refinada espacialmente coherente
   -> eval fold-5 held-out 18 clases (harness US-030) ; comparacion HONESTA E-c vs E-b
```

**Encuadre honesto (clave)**: la evidencia propia (US-020/022b) muestra que ERA5/SRTM
como **columnas tabulares** del XGBoost-AlphaEarth no aportan (delta F1 = 0.0). Por eso
E-c **no** se justifica por re-anadir features tabulares, sino por dos ejes no medidos:
(1) el **estructural** (coherencia espacial de vecinos via CRF/GNN) y (2) el espacio
**denso/grafo** (distinto del XGB tabular ya ablacionado). No se promete mejora.
