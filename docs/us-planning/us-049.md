## 2. Datos REALES disponibles (descargados, verificados)

- **AgroMind**: `data/agromind/agromind_subset_500.json` (500 pares estratificados por `level1_id`, 125 c/u, seed 17; 76 multi-imagen). QA.zip (992kB) completo en `data/agromind/`. Campos: `question`, `options` (dict A/B/C/D, texto O ruta imagen), `answer` (letra), `type_id`, `level1/2/3_id`. Imagenes: zips grandes en HF (se bajan solo las del subset bajo demanda). Eval-only, sin train split.
- **GeoAnalystBench**: `data/geoanalystbench/GeoAnalystBench.csv` (50 tareas, cols: `id`, `Task`, `Instruction`, `Domain Knowledge`, `Dataset Description`, `Human Designed Workflow` [GT pasos], `CodeString` [ref CodeBLEU], `Task Length`).
- Ambos en `.gitignore` (no al Git; via descarga/DVC).

## 3. Tension honesta a documentar (multimodal vs texto)

AgroMind es **multimodal** (preguntas con imagen). Las variantes del reasoner:
- **Gemini 3.5-flash**: multimodal -> evalua AgroMind completo (imagen+texto).
- **Gemma 4 base** (referencia): multimodal -> idem.
- **Qwen3.5/Qwen3-30B-A3B**: **solo texto** (no VLM) -> NO puede ver imagenes. Se evalua sobre el **subconjunto textual** de AgroMind (preguntas que no requieren imagen) y se DOCUMENTA la limitacion; se reporta su numero solo sobre ese subconjunto (no se infla ni se finge multimodalidad). GeoAnalystBench es 100% texto -> Qwen lo corre completo.

## 4. Arquitectura

```
  ml/eval/agent_bench.py
    |
    +-- loaders: load_agromind_subset(path) / load_geoanalystbench(csv)
    +-- runners (por variante): ReasonerVariant (gemini | qwen | gemma-base)
    |     reusa ml.agent.backends.make_backend (Gemini/vLLM) para Qwen/Gemini;
    |     Gemma base via litellm/genai (multimodal).
    +-- AgroMind eval: por item -> prompt (img+pregunta+opciones) -> parse letra
    |     -> exact_match; + DeepEval judge (hallucination, answer relevancy).
    +-- GeoAnalystBench eval: por task -> Instruction -> workflow+codigo
    |     -> semantic sim vs Human Designed Workflow; CodeBLEU vs CodeString.
    +-- metrics: exact_match, f1_squad, bertscore, tool_call_acc, hallucination,
    |     pass_rate, codebleu. Agregadas sobre 3 seeds -> mean +- std.
    +-- report: HTML (tabla comparativa A/B/base + error bars) en reports/agent_bench/.
    +-- MLflow: track_experiment("us049_agent_bench", tags code/data version).
```

## 11. Riesgos y mitigaciones

| Riesgo | Mitigacion |
|--------|------------|
| Imagenes AgroMind pesadas (9.5GB) | Bajar SOLO las del subset 500 (`download_agromind_images.py`), no los zips completos. |
| Qwen no multimodal en AgroMind | Evaluar Qwen en subset textual; documentar; nunca fingir multimodalidad. |
| DeepEval/judge requiere LLM (costo/red) | Judge inyectable; mockeable en tests; corrida real opcional con budget. |
| codebleu lib no en deps | Implementar CodeBLEU minimo (n-gram + AST si tree-sitter disponible) o usar sacrebleu como proxy documentado. |
| Fine-tune accidental = leakage | El harness NO tiene paso de entrenamiento (AC-3); solo inferencia. |
