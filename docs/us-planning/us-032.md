**Rama sugerida**: `feature/E5-US-032-pastis-filter-dominance`
**Plan vigente**: `context/RefinamientoPlaneacionAgroSatCopilot_v8.md` (US-032, lineas 1175-1196; ADR-009)
**Base correcta**: `ml/data/pastis_filter.py` ya traido de `origin/user/iavila/pastis-preparation-for-farslip` (presente en `main`). **NO** mezclar con `abocanegra/semana-5` (84 commits detras, 11 conflictos).
**Insumo de**: US-036 (FarSLIP / Stage-1 4 clases [Meadow=1, Soft winter wheat=2, Corn=3, Grapevine=8]).

> **Objetivo**: extender `PastisFilter` (de Isaac) con un **modo nuevo `dominance_ratio`** que mantenga
> un patch si `Meadow_px <= ratio * (2da clase mas grande EN ESE PATCH)`, con `ratio=3` por defecto, y
> que sea **parametrizable por `n_classes` / `target_classes`** (conjunto de clases objetivo dinamico).
> El **modo `coverage`/`min_coverage` legacy queda intacto** (no debe alterar
> `data/pastis_farslip_filtered_splits.json`). El histograma per-patch se computa con
> `np.bincount(target[0].ravel())` sobre `TARGET_<id>.npy (3,128,128)` uint8, canal 0
> (0=Background, 1-18 cultivos, 19=Void). Tests verdes en `tests/ml/data/`.

> **CORRECCIONES CRITICAS A LA US (verificadas en recon contra disco)**:
> 1. **El "filtro 3:1" NO existe hoy**. `pastis_filter.py` solo implementa un **umbral de cobertura
>    combinada** (`_passes`: `coverage = px(target_classes)/px(validos) >= min_coverage`, default 0.50).
>    `dominance_ratio` es **logica NUEVA** (ratio dominante:segunda), NO un test del umbral existente.
> 2. **Cambio aditivo, no destructivo**. `_passes` debe **bifurcar por `self.mode`** conservando el
>    cuerpo actual como rama `mode=="coverage"` (default). La firma `tuple[bool, float]` se PRESERVA
>    (la rama `dominance_ratio` devuelve el ratio observado `meadow/second` como 2.o valor) para no
>    romper `filter_patch_ids`/`filter_folds`/`coverage_stats`, que desempaquetan exactamente 2 valores.
> 3. **Background(0) y Void(19) NO deben depender de `ignore_index`**. `_load_mask` devuelve el canal 0
>    CRUDO (Void=19, Background=0 sin remapear), pero el default `ignore_index=255`. El modo
>    `dominance_ratio` debe **excluir explicitamente {0, 19} del histograma** sin depender de
>    `ignore_index`, o el ratio se contamina (riesgo R-IGNORE).
> 4. **`self.target_classes` es un `set`** (no lista) — la "2da clase mas grande" se halla **ordenando
>    por conteo**, NO por indice. Se restringe el argmax al conjunto `target_classes` (esto es la
>    parametrizacion por `n_classes`): la 2da clase es la mayor entre `target_classes \ {Meadow}`.
> 5. **Edge case `second_px == 0`** (patch sin ninguna otra clase objetivo distinta de Meadow): el plan
>    NO lo especifica. `3 * 0 = 0` descartaria cualquier patch con >0 px de Meadow. Se fija politica
>    explicita y testeada: **drop si hay Meadow y no hay competidor** (`second_px==0 and meadow_px>0 -> False`);
>    **keep si el patch no tiene Meadow** (`meadow_px==0 -> True`, no esta dominado). Documentado en R-EDGE.

> **OJO ALCANCE**: `pastis_filter.py` es **UN solo archivo** (write-conflict) -> **1 agente ml**, no
> paralelizable (Seccion 5). El entregable es codigo + tests; **NO se regenera ni se toca**
> `pastis_farslip_filtered_splits.json` (es producto del modo coverage legacy; contrato fijo, Seccion 8).

## 2. Arquitectura de la solucion

```
   PastisFilter(pastis_root, target_classes, min_coverage,
                mode="coverage"|"dominance_ratio", ratio=3.0, meadow_class=1,
                ignore_index, annotation_key=0, verbose)
                                    |
                          _load_mask(pid) -> (H,W) int32   (canal 0 del TARGET (3,128,128))
                                    |
                                    v
                          _passes(mask) -> (bool, float)        <-- UNICO punto que bifurca
                          +---------------------------------+
                          |  if self.mode == "coverage":    |   (rama LEGACY, sin cambios)
                          |     valid = mask != ignore_index|
                          |     coverage = px(target)/px(valid)
                          |     return coverage>=min_cov, coverage
                          |---------------------------------|
                          |  else  # "dominance_ratio"      |   (rama NUEVA)
                          |     -> _passes_dominance(mask)   |
                          +---------------------------------+
                                    |
                                    v
   _passes_dominance(mask) -> (bool, float):
       hist = np.bincount(mask.ravel(), minlength=20)      # 20 bins: 0..19
       meadow_px = int(hist[meadow_class])                 # default class 1
       if meadow_px == 0: return True, 0.0                 # no dominado -> KEEP
       # 2da clase mas grande ENTRE target_classes, excluyendo Meadow, bg(0), void(19)
       candidates = [c for c in target_classes if c not in (meadow_class, 0, 19)]
       second_px = max((int(hist[c]) for c in candidates), default=0)
       if second_px == 0: return False, float("inf")       # Meadow y sin competidor -> DROP
       ratio_obs = meadow_px / second_px
       return meadow_px <= ratio * second_px, ratio_obs
                                    |
        +---------------------------+---------------------------+
        v                                                       v
   filter_patch_ids / filter_folds (polimorficos por mode)   coverage_stats (EDA; 2.o valor = ratio
   -> list[int] de patch_ids que pasan                        en modo dominance; claves coverage-* se
                                                              documentan como no aplicables en dominance)
```

**Principio rector**: cambio **estrictamente aditivo**. El default es `mode="coverage"` -> el
comportamiento legacy (y por tanto `pastis_farslip_filtered_splits.json`) es bit-identico. La rama
`dominance_ratio`: (a) usa `np.bincount` sobre el canal 0; (b) excluye Background/Void **por id literal**
(no por `ignore_index`); (c) restringe la 2da clase a `target_classes` (parametrizacion `n_classes`);
(d) conserva la firma `(bool, float)`.

```python

    self,
    pastis_root: Path | str,
    target_classes: list[int] | None = None,
    min_coverage: float = 0.50,
    ignore_index: int = 255,
    annotation_key: int = 0,
    verbose: bool = False,
    *,
    mode: Literal["coverage", "dominance_ratio"] = "coverage",
    ratio: float = 3.0,
    meadow_class: int = 1,
) -> None:
    """Scan PASTIS-R annotations and keep patch IDs that pass a filter.

    Two filtering modes (the legacy ``coverage`` is the default and is

    - ``coverage`` (legacy): keep if the COMBINED coverage of ``target_classes``
      over valid (``!= ignore_index``) pixels is ``>= min_coverage``.
    - ``dominance_ratio`` (new): keep if ``Meadow_px <= ratio * second_px``,
      where ``second_px`` is the largest count, IN THAT PATCH, among
      ``target_classes`` excluding Meadow, Background (0) and Void (19). This
      drops patches over-dominated by Meadow (class 1).

    Args:
        ...
        mode: filtering strategy. ``"coverage"`` (default) or
            ``"dominance_ratio"``.
        ratio: max Meadow-to-second-class ratio kept in ``dominance_ratio``
            mode (default 3.0 -> the 3:1 rule).
        meadow_class: class id treated as the dominant class to bound
            (default 1 = Meadow in the PASTIS 20-class scheme).
    """
    ...
```

### 4.2 `ml/data/pastis_filter.py` — `_passes` (bifurca) + `_passes_dominance` (nuevo)

    coverage fraction (legacy). In ``dominance_ratio`` mode ``metric`` is the
    observed ``Meadow_px / second_px`` ratio. The 2-tuple shape is PRESERVED so
    ``filter_patch_ids`` / ``filter_folds`` / ``coverage_stats`` are unaffected.
    """
    if self.mode == "dominance_ratio":
        return self._passes_dominance(mask)
    # --- legacy coverage branch (unchanged) ---

    """3:1 Meadow per-patch dominance filter.

    Builds a 20-bin histogram via ``np.bincount(mask.ravel(), minlength=20)``
    over the semantic channel. Keeps the patch when
    ``Meadow_px <= self.ratio * second_px``. ``second_px`` is the largest count

    ``ignore_index``) so the ratio is not contaminated.

    Edge cases:
        - ``Meadow_px == 0``: keep (patch not Meadow-dominated), metric 0.0.

          drop, metric ``inf``.

    Returns:
        ``(keep, ratio_observed)`` where ``ratio_observed = Meadow_px /
        second_px`` (``inf`` when ``second_px == 0``).
    """

> **Contrato clave**: `_passes` SIEMPRE devuelve `tuple[bool, float]` (no se anade un 3.er valor). Esto
> garantiza que `filter_patch_ids` (`passes, cov = self._passes(mask)`), `filter_folds` y `coverage_stats`

> tocar su cuerpo (solo el logging de `filter_folds` cambia el label `min_coverage` -> `ratio` cosmeticamente).
