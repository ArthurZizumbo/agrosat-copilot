## 2. Enfoque tecnico

### 2.1 Naturaleza del entregable

US-063 es **documental**: no toca codigo de aplicacion ni infraestructura ejecutable. El unico
artefacto es `docs/cloud/comparativa_proveedores.md` (la carpeta `docs/cloud/` no existe aun y se
crea). La fuerza del documento es que **cada decision se ancla a un hecho REAL ya existente** en el
repo (Terraform, memoria del proyecto, plan v8), no a opiniones genericas de cloud.

### 2.2 Anclas reales del proyecto (citar en el doc, no inventar)

| Afirmacion del doc | Fuente real (verificada) |
|--------------------|--------------------------|
| GCP es el plano de control primario | `infrastructure/terraform/modules/gcp/main.tf` (Cloud Run, Cloud SQL PostGIS+pgvector, GCS, Pub/Sub, Vertex AI, Artifact Registry, Secret Manager). |
| Cloud Run scale-to-zero | `cloudrun_min_instances = 0` en `infrastructure/terraform/environments/dev/main.tf:44` (var `cloudrun_min_instances`, `gcp/variables.tf:57`). Operativo objetivo ~$115 USD/mes. |
| Cloud SQL dev apagada (FinOps) | `db_activation_policy = "NEVER"` en `infrastructure/terraform/environments/dev/main.tf:43`; var `db_activation_policy` (`gcp/variables.tf:40`) evita drift. |
| H100 = Azure, del sponsor, 24/7 sin costo al equipo | Modulo Azure `infrastructure/terraform/modules/azure/main.tf` (`Standard_NC40ads_H100_v5`, H100 NVL 96GB, `westeurope`); VM real `gjcamacho-gpuh1` prestada por el sponsor, 24/7. Bloque Azure en `environments/dev/main.tf:54` esta **comentado** (fuera de scope TF) porque la VM la administra el sponsor, no nuestro Terraform. |
| Region Azure proxima a Italia | `azure/variables.tf:2` (`westeurope = Italy proximity, H100 availability`). |
| EO via AlphaEarth en GEE | AlphaEarth Foundations `SATELLITE_EMBEDDING/V1/ANNUAL`, **data v1.1**, 64-dim, global incl. Mexico, **CC-BY-4.0**. NUNCA "v2.1". |
| MLOps real | Dagster (`dagster_project/`) + MLflow server **Docker :5010** (no `./mlruns`) + DVC (GCS remote). Vertex AI Agent Engine para el agente ADK (Gemini 2.5 Pro reasoner). |
| On-prem / serving | Qwen3.5-35B-A3B vLLM GPTQ-Int4 single-GPU corre en la H100 del sponsor (soberania de datos). Gemma 4 LoRA OUT (ADR-009 future). |

### 2.3 FinOps reales a incluir (cifras EXACTAS)

- Operativo objetivo **~$115 USD/mes** (Cloud Run scale-to-zero, `min_instances=0`).
- Training unico historico **$262 (spot) - $602 (on-demand)**; hoy la H100 del sponsor es **24/7 SIN
  costo al equipo** -> el coste de training efectivo del equipo tiende a $0.
- GCP acumulado a la fecha **~$0.30-0.49 USD**.
- Gemini API: centavos (**~$0.0001/descripcion FarSLIP**).
- **Caveat de creditos (factor partnerships)**: el "Trial credit for GenAI App Builder" ($17,178) es
  de **Vertex AI Search / Agent Builder**, **NO** cubre la SKU de generacion de texto de Gemini API.
  Esta nota es OBLIGATORIA para no sobre-vender los creditos academicos de GCP.

### 2.4 Tratamiento del factor "precio H100 on-demand y spot"

Es el factor mas sensible a placeholders. Regla de redaccion:

1. Precios de **lista por proveedor** (GCP A3/H100, Azure `NC*_H100_v5`, AWS `p5`/SageMaker,
   IBM Cloud) se presentan como **precios publicados, con fuente (pagina de pricing del proveedor) y
   fecha de consulta** explicitas. Se marcan como referencia externa, no como gasto del proyecto.
2. El **gasto real del proyecto en H100 = $0** (sponsor), y eso es justamente el argumento de
   decision: no compramos H100 en ningun cloud porque el sponsor la presta 24/7.
3. Si a la fecha de redaccion algun precio no se puede confirmar contra fuente, se omite el numero,
   se deja la celda como "no verificado a la fecha — ver blocker" y se anota en
   `docs/blockers/epic10-notas.md`. NO se inventa.
