### 1.2 API real del paquete `eurocropsml`

**Instalacion**: `poetry add eurocropsml` (PyPI; trae torch/numpy; CPU-friendly).

**CLI** (`eurocropsml-cli`):
```
eurocropsml-cli acquisition eurocrops [config | get-data]
eurocropsml-cli datasets    eurocrops [config | download | preprocess | build-splits]
```
- `datasets eurocrops config` — muestra/edita la config (override inline `[OVERRIDES]...` o `--config-path`).
- `datasets eurocrops download` — descarga desde Zenodo (resuelve version interactivamente -> automatizar con override).
- `datasets eurocrops preprocess` — materializa los `.npz` por parcela (13 bandas + timestamps + centroide + `EC_hcat_c`).
- `datasets eurocrops build-splits` — **genera los splits k-shot pre-codificados** (1/5/10/20/100/200/500-shot) segun la config de regiones.

**API Python** (preferida en el pipeline, evita el CLI interactivo):
- `eurocropsml.dataset.download.download_dataset(...)` (+ `select_version`, `get_user_choice`).
- `eurocropsml.dataset.splits.create_splits(...)` (+ `split_dataset_by_class`, `split_dataset_by_region`, `get_split_dir`).
- `eurocropsml.dataset.dataset.EuroCropsDataset` — dataset PyTorch-style; cada item = serie S2 + label HCAT.
- Config: `eurocropsml.dataset.config.EuroCropsSplit` con atributos clave:
  - `pretrain_regions` / `finetune_regions` — paises source / destino (ej. `["latvia","portugal"]` / `["estonia"]`).
  - `pretrain_classes` / `finetune_classes` — clases HCAT por fase.
  - `num_samples` — el **k** del k-shot (1,5,10,20,100,200,500).
  - `meadow_class` — downsampling opcional de pasture/meadow (mitiga long-tail, igual que el 45% grassland de PASTIS).
  - `EuroCropsDatasetConfig` — config fina del dataset (bandas, normalizacion).

**Referencia del paper (Tabla II, 500-shot)** — los numeros a reproducir/comparar:
| Setting | Accuracy @500-shot |
|---------|-------------------:|
| Pre-train en LV -> EE | **0.66** |
| Pre-train en LV+PT -> EE | 0.62 |
| Sin pre-train (random init) -> EE | **0.57** |

> El "0.66 vs 0.57" del enunciado = pre-train-LV vs sin-pretrain @500-shot. Es **accuracy** del
> protocolo del paper (red neuronal temporal); nuestra curva XGB es una **referencia tabular
> propia** (F1-macro), comparable en forma (sube con k) pero NO identica en valor: se enmarca
> como "domain gap medido con el baseline tabular", citando el paper como referencia metodologica.

## 3. Arquitectura del pipeline

### 3.1 Modulo `ml/transfer/eurocropsml_fewshot.py`

```
ml/transfer/
  __init__.py
  eurocropsml_fewshot.py      # pipeline few-shot (loop sobre k, XGB sobre features S2)
  label_align.py              # EC_hcat_c -> macro HCAT via crosswalk US-074 (reusable)
```

Funciones publicas (type hints obligatorios, docstrings Google-style en ingles):

| Funcion | Responsabilidad |
|---------|-----------------|
| `download_eurocropsml(root: Path, regions: tuple[str,...]) -> Path` | Wrapper sobre `eurocropsml.dataset.download.download_dataset` con version fijada (no-interactivo); idempotente (skip si ya existe). Devuelve el dir del subset. |
| `build_fewshot_splits(root, *, pretrain, finetune, k_shots) -> dict` | Wrapper sobre `eurocropsml.dataset.splits.create_splits` con `EuroCropsSplit(pretrain_regions=..., finetune_regions=..., num_samples=k)`; cachea por (source,target,k). |
| `parcel_feature_vector(series: np.ndarray) -> np.ndarray` | Reduce la serie temporal S2 (13 bandas x T) a un **vector fijo** por parcela (mean/std/percentiles por banda + tendencia simple). Es el analogo tabular del "AlphaEarth 64-dim" para datos sin AlphaEarth. |
| `align_labels_to_hcat_macro(hcat_codes: pl.Series) -> pl.Series` | `EC_hcat_c` -> macro HCAT (11 grupos) via `eurocrops_hcat3.csv` + `hcat_crosswalk.parquet` (US-074). Clases sin mapeo -> `null-class` (NO falso negativo, §7 US-074). |
| `train_xgb_kshot(x_train, y_train, x_test, y_test) -> dict` | Entrena `build_estimator("xgb", _XGB_BASE_PARAMS)` (RECIPE del baseline, `ml/train/baseline.py`) sobre las k muestras locales; reporta F1-macro en el test. Reusa `SpatialXGBClassifier` para folds sin todas las clases. |
| `run_fewshot_curve(root, *, source, target, k_shots, seeds) -> pl.DataFrame` | Loop sobre k (y sobre seeds para barras de error); devuelve frame `(source,target,k,seed,f1_macro,n_classes)`. Decorada con `@track_experiment` (MLflow). |

**Recipe reusado (no reescrito)**: `build_estimator("xgb", {...multi:softprob, hist, n_estimators=400, max_depth=6...})`
de `ml/train/baseline.py` (mismo recipe que `ml/agent/tools/classify.py::_load_classifier`).
El RECIPE = XGB sobre un vector fijo por parcela; el vector cambia (S2 reducido, no AlphaEarth)
porque EuroCropsML no trae AlphaEarth — esto se documenta como decision honesta.

### 3.2 Decision honesta: el feature vector (AlphaEarth ausente)

El enunciado pide "AlphaEarth 64-dim + XGBoost". EuroCropsML **no contiene embeddings AlphaEarth**;
trae la serie S2 L1C (13 bandas). Tres opciones, decision documentada:

1. **(ELEGIDA) Vector tabular derivado de la serie S2 propia de EuroCropsML** (mean/std/min/max/
   percentiles + pendiente por banda -> ~64-90 dims). Es 100% del dato real del dataset, reproduce
   el *recipe* (XGB sobre vector fijo), y mantiene la comparabilidad con el paper (mismo input que
   ellos, distinto clasificador). **Cero dependencia de GEE.**
2. (Descartada para el camino base) Re-muestrear AlphaEarth V1/ANNUAL en los centroides de las
   parcelas EuroCropsML via GEE (`sample_alphaearth_at_coords`). Daria el "AlphaEarth real" pero
   requiere jobs GEE de horas/dias sobre EE+LV+PT y un service account con cuota -> FUTURE,
   se deja como celda opcional/anexo, NO bloquea la curva.
3. (Descartada) Inventar embeddings -> viola la regla Arthur.

> La curva se titula "F1-macro vs k (baseline tabular XGB sobre features S2 de EuroCropsML)" y el
> texto aclara: el recipe es el del baseline AlphaEarth+XGB, el *input* es la serie S2 del dataset
> (no AlphaEarth) porque EuroCropsML no provee AlphaEarth; la opcion AlphaEarth-via-GEE queda FUTURE.

### 3.3 Alineacion HCAT (reuso US-074)

- `EC_hcat_c` (codigo HCAT EuroCrops, 10-dig) ya es del **mismo espacio** que `hcat_leaf_code` del
  crosswalk US-074 (`data/reference/hcat_crosswalk.parquet`) y de `eurocrops_hcat3.csv` (384 nodos).
- Colapso a macro: `EC_hcat_c -> hcat_group_code (6-dig significativos) -> macro_hcat_group` (11 grupos),
  exactamente la regla de US-074 §3.2. Asi la curva se reporta sobre el **mismo label-space**
  (`hcat-macro`) que el resto de E12, mitigando el long-tail (Meadow/grassland).
- Clases EuroCropsML sin equivalente en el crosswalk PASTIS-18 -> se tratan como `null-class`
  (partial-label, §7 US-074): se reportan aparte, no como error duro.
- **NO se toca** `ml/eval/class_remap.py` ni `ml/agent/tools/classify.py` (el label-space ya esta
  registrado por US-074); `label_align.py` solo *consume* el parquet.

   y anotar que 200/500 quedan pendientes — la curva sigue siendo REAL, solo mas corta.

   `docs/blockers/epic12-vm-setup.md` (ya existe) con: DOI intentado, error exacto, comando, fecha;
   dejar `ml/transfer/eurocropsml_fewshot.py` + notebook + tests LISTOS (con mocks verdes) para
   re-ejecutar cuando haya datos. El notebook en modo `degraded=true` muestra el pipeline y un
   placeholder explicito "datos no descargados — ver blocker", **sin numeros inventados**.
