### 2.1 Decisiones tecnicas clave

| # | Decision | Justificacion | Trade-off rechazado |
|---|----------|---------------|---------------------|
| D1 | **CV espacial = `build_spatial_kfold` (US-016, H3+KMeans+buffer 1km)**, NO los folds PASTIS-R 1-5 ni `KFold` aleatorio | El dataset parcel-level (85.951 parcelas) ya no es patch-level; `build_spatial_kfold` opera sobre geometrias reales de parcela y aplica buffer anti-leakage. Es la herramienta canonica del repo para spatial CV sobre parcelas. Regla `ml/CLAUDE.md`: spatial CV obligatorio | Folds PASTIS-R 1-5: definidos a nivel patch, no parcela; usarlos requeriria propagar `fold` por patch (existe la col `fold` pero el buffer anti-vecinos lo da H3). `KFold` aleatorio: leakage espacial garantizado |
| D2 | **RF + XGBoost, NO LightGBM** | El CA del v6 nombra explicitamente `RandomForestClassifier` + `XGBClassifier`. LightGBM esta en el stack (`agrosat-ml-baseline`) pero el v6 US-018 no lo pide para el baseline del Avance 3 | LightGBM como tercer modelo: scope creep; se reserva para ensambles EPIC 6 |

```python
from dataclasses import dataclass
from typing import Literal
import polars as pl
from sklearn.base import ClassifierMixin

ModelKind = Literal["rf", "xgb"]

@dataclass(frozen=True)
class BaselineResult:
    """Resultado de entrenar un baseline.

    Attributes:
        model: estimador sklearn/xgboost ya fiteado sobre el dataset completo.
        model_kind: "rf" | "xgb".
        metrics: 5 metricas sobre out-of-fold predictions (spatial CV).
        cv_metrics: dict {metric: (mean, std)} sobre los 5 folds.
        feature_cols: nombres de las columnas usadas como features.
        best_params: hiperparametros (de GridSearchCV o los base).
        label_classes: clases originales (orden del LabelEncoder).
    """
    model: ClassifierMixin
    model_kind: ModelKind
    metrics: dict[str, float]
    cv_metrics: dict[str, tuple[float, float]]
    feature_cols: tuple[str, ...]
    best_params: dict[str, object]
    label_classes: tuple[int, ...]

def train_one_model(
    df: pl.DataFrame,
    *,
    model: ModelKind,
    hyperparams: dict[str, object] | None = None,
    k_folds: int = 5,
    buffer_km: float = 1.0,
    random_state: int = 42,
) -> BaselineResult:
    """Entrena un baseline (RF o XGB) con evaluacion spatial CV.

    Hace: carga features, spatial CV (build_spatial_kfold), fit por fold
    con scaler anti-leakage, out-of-fold predictions, fit final sobre todo
    el dataset. Devuelve BaselineResult.
    """

def tune_baseline(
    df: pl.DataFrame,
    *,
    model: ModelKind,
    param_grid: dict[str, list] | None = None,
    k_folds: int = 5,
    buffer_km: float = 1.0,
    scoring: str = "f1_macro",
    random_state: int = 42,
) -> dict[str, object]:
    """GridSearchCV ligero sobre spatial CV. Devuelve best_params_.

    El `cv` de GridSearchCV es la lista de splits espaciales (no un entero)
    para garantizar que el tuning respeta la particion geografica.
    """

def evaluate_with_spatial_cv(
    df: pl.DataFrame,
    model_factory: "Callable[[], ClassifierMixin]",
    *,
    k_folds: int = 5,
    buffer_km: float = 1.0,
    random_state: int = 42,
) -> tuple[dict[str, tuple[float, float]], np.ndarray, np.ndarray]:
    """CV espacial: devuelve (cv_metrics, y_true_oof, y_pred_oof)."""
```
