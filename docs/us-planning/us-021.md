### 2.1 Decisiones tecnicas clave

| # | Decision | Justificacion | Trade-off rechazado |
|---|----------|---------------|---------------------|
| D1 | **`ml/eval/learning_curves.py` NUEVO**, separado de `metrics.py` (US-019) e `interpretability.py` (US-020) | Cohesion: diagnostico de sub/sobreajuste es un dominio propio dentro de `ml/eval/`. `metrics.py` = metricas puntuales, `interpretability.py` = SHAP, `learning_curves.py` = curvas. Los 3 se re-exportan desde `ml/eval/__init__.py` | Un solo `ml/eval/diagnostics.py` gigante: mezcla 3 responsabilidades |
| D2 | **Materializar los splits espaciales en una `list` antes de pasarlos a `learning_curve`/`validation_curve`** | `build_spatial_kfold` produce `FoldAssignment` con `parcel_id`; se convierten a `(train_idx, test_idx)` posicionales. **`learning_curve` reusa el `cv` una vez por cada `train_size`** — si se pasa un generador, se agota tras el primer tamano y los demas quedan sin folds. La lista materializada es reutilizable. Verificado con Context7 (la doc usa splitters/listas, no generadores de un solo uso) | Pasar un generador: silenciosamente las curvas usan solo el primer `train_size` con folds, el resto vacio |
| D3 | **Las curvas RE-ENTRENAN estimadores frescos**, NO cargan los joblib de US-019 | `learning_curve` por diseno entrena el estimador N×M veces (N tamanos × M folds). Necesita un estimador *sin fitear* (un factory). Los joblib de US-019 son modelos ya fiteados sobre todo el dataset — inutiles para una curva. US-021 usa el mismo *factory* de hiperparametros de US-019 | Cargar el joblib: no sirve, `learning_curve` necesita re-fitear |
| D4 | **`scoring="accuracy"`** en las curvas (el CA dice "accuracy train/val") | El CA literal pide accuracy. F1-macro es la metrica principal del baseline (US-019), pero el CA de US-021 especifica accuracy para las curvas — se respeta. El notebook puede anadir una curva F1-macro complementaria como "nice to have" | F1-macro en las curvas: contradice el CA literal |
| D5 | **Umbrales de diagnostico parametricos** (`gap_threshold=0.10`, `low_acc_threshold=0.65`) | El CA fija `>10%` para sobreajuste y "ambos bajos" para subajuste; se exponen como parametros con esos defaults para que EPIC 5/6 los reuse con otros umbrales si aplica | Umbrales hardcodeados: no reutilizable |
| D6 | **`train_sizes` como fracciones, no conteos absolutos** | `[0.1..1.0]` se adapta a cualquier tamano de dataset (el subset puede crecer). `learning_curve` acepta floats como fraccion del train de cada fold | Conteos absolutos (`[50, 100, ...]`): fragiles si cambia el tamano del dataset |
| D7 | **Subsample opcional para acelerar** (`max_samples` parametrico) | `learning_curve` sobre 85k × 187, 7 tamanos × 5 folds × 2 modelos = 70 entrenamientos. RF con `n_estimators=300` puede tardar. `max_samples` permite un subsample estratificado para dev/CI; el notebook final corre sobre el dataset completo | Siempre dataset completo: tests `slow` muy lentos |
| D8 | **`diagnose_fit` opera sobre el resultado de la curva de aprendizaje** (no re-entrena) | El verdict (overfit/underfit/good_fit) se deriva de los scores ya calculados en `LearningCurveResult` (gap en el tamano maximo). Funcion pura, trivial de testear | Re-entrenar dentro de `diagnose_fit`: duplica computo |

### 2.3 Justificacion del stack

- **scikit-learn 1.8** (`pyproject.toml:83`): `learning_curve`, `validation_curve` — ambas aceptan `cv` como iterable de splits. **API verificada con Context7**.

- **polars 1.x**: I/O del parquet (regla `ml/CLAUDE.md NEVER pandas`). Conversion a numpy en el borde sklearn.
- **geopandas + h3** (grupo geo): requeridos por `build_spatial_kfold`.

## 4. Interfaces publicas (signatures)

### 4.1 `ml/eval/learning_curves.py`

```python
from dataclasses import dataclass
from typing import Literal
import numpy as np
import polars as pl
from matplotlib.figure import Figure
from sklearn.base import ClassifierMixin

FitVerdict = Literal["overfit", "underfit", "good_fit"]

@dataclass(frozen=True)
class LearningCurveResult:
    """Resultado de una curva de aprendizaje.

    Attributes:
        train_sizes_abs: numero absoluto de muestras por punto (n,).
        train_scores_mean: accuracy media de train por tamano (n,).
        train_scores_std: desviacion de train (n,).
        val_scores_mean: accuracy media de validacion por tamano (n,).
        val_scores_std: desviacion de validacion (n,).
        scoring: metrica usada ("accuracy").
    """
    train_sizes_abs: np.ndarray
    train_scores_mean: np.ndarray
    train_scores_std: np.ndarray
    val_scores_mean: np.ndarray
    val_scores_std: np.ndarray
    scoring: str

@dataclass(frozen=True)
class ValidationCurveResult:
    """Resultado de una curva de validacion sobre un hiperparametro.

    Attributes:
        param_name: nombre del hiperparametro variado.
        param_range: valores evaluados.
        train_scores_mean / train_scores_std: accuracy de train.
        val_scores_mean / val_scores_std: accuracy de validacion.
    """
    param_name: str
    param_range: list
    train_scores_mean: np.ndarray
    train_scores_std: np.ndarray
    val_scores_mean: np.ndarray
    val_scores_std: np.ndarray

@dataclass(frozen=True)
class FitDiagnosis:
    """Diagnostico de sub/sobreajuste.

    Attributes:
        verdict: "overfit" | "underfit" | "good_fit".
        gap: accuracy_train - accuracy_val en el tamano maximo.
        train_acc_max: accuracy de train en el tamano maximo.
        val_acc_max: accuracy de validacion en el tamano maximo.
        explanation: texto que justifica el verdict.
    """
    verdict: FitVerdict
    gap: float
    train_acc_max: float
    val_acc_max: float
    explanation: str

def plot_learning_curve(
    estimator: ClassifierMixin,

    *,
    train_sizes: list[float] | None = None,
    scoring: str = "accuracy",
    max_samples: int = 0,
    random_state: int = 42,
) -> tuple[LearningCurveResult, Figure]:
    """Curva de aprendizaje con spatial CV.

    `cv_splits` DEBE ser una lista materializada (no un generador): la
    funcion reusa el cv por cada `train_size`.
    """

def plot_validation_curve(
    estimator: ClassifierMixin,
    df: pl.DataFrame,
    param_name: str,
    param_range: list,
    cv_splits: list[tuple[np.ndarray, np.ndarray]],
    *,
    scoring: str = "accuracy",
    max_samples: int = 0,
    random_state: int = 42,
) -> tuple[ValidationCurveResult, Figure]:
    """Curva de validacion sobre un hiperparametro, con spatial CV."""

def diagnose_fit(
    result: LearningCurveResult,
    *,
    gap_threshold: float = 0.10,
    low_acc_threshold: float = 0.65,
) -> FitDiagnosis:
    """Diagnostica sub/sobreajuste desde una curva de aprendizaje.

    Reglas:
        gap > gap_threshold                          -> "overfit"
        train_acc < low_acc AND val_acc < low_acc    -> "underfit"
        resto                                        -> "good_fit"
    """
```
