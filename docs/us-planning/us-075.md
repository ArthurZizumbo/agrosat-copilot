### 1.3 Sen4AgriNet S4A — formato netCDF REAL (verificado en Orion-AI-Lab/S4A-Models@master)

Fuente oficial del pipeline: `utils/PAD_dataset.py` + `utils/settings/config.py` (repo
`Orion-AI-Lab/S4A-Models`, branch `master`). Dataset HF: `orion-ai-lab/S4A` (espejo
`paren8esis/S4A`). **Tamano total split completo: 281 GB** -> NO se baja completo.

**Estructura del patch netCDF** (`<year>_<tile>_patch_<x>_<y>.nc`, p.ej. `2019_31TCF_patch_10_14`):
- **Grupos por banda**: 13 bandas Sentinel-2 como variables/grupos netCDF:
  `B01 B02 B03 B04 B05 B06 B07 B08 B09 B10 B11 B12 B8A`. Cada banda tiene su propia
  dimension `time` (ntime ~30-50 adquisiciones/ano) y resolucion nativa:
  - 10 m: `B02 B03 B04 B08` -> 366x366
  - 20 m: `B05 B06 B07 B8A B11 B12` -> 183x183
  - 60 m: `B01 B09 B10` -> 61x61
- **Banda de referencia**: `REFERENCE_BAND = 'B02'` (10 m). Las bandas 20/60 m se
  "estiran" a 10 m con `np.repeat(expand_ratio)` (`expand_ratio = BANDS[band]/BANDS[ref]`).
- **2 variables de etiquetas**: `labels` (FAO-ICC crop id por pixel, anual, uint32) y
  `parcels` (mascara/rasterizacion LPIS de parcelas). `IMG_SIZE = 366`, `NORMALIZATION_DIV = 10000`.
- Atributo global `patch_year`. COCO json indexa los patches por tile/split.

**Configs HF para descarga selectiva** (clave para NO bajar 281 GB):
`complete`, **`cat_2019`** (Catalonia 2019), **`cat_2020`** (Catalonia 2020), **`fr_2019`** (Francia 2019).
Naming de patch: `YYYY_<TILE>_patch_xx_yy` con country code en el tile (ES=Catalonia 31Txx, FR=31Txx).

> **Nota de tile**: el plan v8 cita "31TCG" para Catalonia. Los ejemplos del dataset usan
> `31TCF`/`31TDF` para Catalonia. El adapter NO hardcodea el tile: filtra por `allow_patterns`
> del prefijo `cat_2019`/`cat_2020` y selecciona N patches con parcelas no vacias. El doc
> reporta el tile real que baje (verificado contra el COCO/listado del config), sin inventar.

### 1.4 Pipeline oficial `PAD_dataset.py` (a replicar en el adapter, verbatim conceptual)

`get_medians(netcdf, start_bin, window)` por banda:
1. `date_range = pd.date_range(f'{year}-01-01', f'{year+1}-01-01', freq='1M')` (12 bins mensuales).
2. `band_data.groupby_bins('time', bins=date_range, right=True, labels=date_range[:-1]).median('time')`
   -> **mediana mensual** (binning mensual).
3. `.resample(time_bins='1M').median('time_bins')` -> inicializa meses sin datos a NaN.
4. `.interpolate_na('time_bins', method='linear', fill_value='extrapolate')` -> rellena
   meses NaN por interpolacion lineal (extrapola los extremos).
5. `.isel(time_bins=slice(start_bin, start_bin+window))` -> ventana temporal (`window_len`,
   default 12; `fixed_window` = meses 4..9 = 6 meses).
6. Bandas 20/60 m -> `np.repeat(expand_ratio)` a 10 m.
7. Salida `(window, num_bands, H, W)` -> transpose a `(T, C, H, W)`.

`get_labels`: carga `labels` (uint32, FAO-ICC), 1 label/ano. `__getitem__`:
- Norm: `medians /= NORMALIZATION_DIV` (10000) -> `[0,1]`.
- **linear_encoder**: `for crop_id, linear_id in linear_encoder.items(): out[labels==crop_id]=linear_id`;
  todo lo que NO este en `linear_encoder.values()` -> 0 (background). Crop ids FAO-ICC seleccionados
  (`SELECTED_CLASSES`): `110 Wheat, 120 Maize, 140 Sorghum, 150 Barley, 160 Rye, 170 Oats,
  330 Grapes, 435 Rapeseed, 438 Sunflower, 510 Potatoes, 770 Peas` (+ 0 background).

### 3.2 Adapter `ml/data/sen4agrinet_adapter.py`

`Sen4AgriNetDataset(Dataset)` — replica el contrato de `PASTISSegmentationDataset`:

```
__getitem__(i) -> (x: torch.Tensor (T, 10, H, W) float32, y: torch.Tensor (H, W) int64)
```

Componentes (todos derivados del `PAD_dataset.py` oficial, sin inventar):

1. **Lectura netCDF** con `netCDF4.Dataset(path)` + `xarray.open_dataset(NetCDF4DataStore(nc[band]))`
   por banda (igual que el oficial).
2. **Seleccion de 10 bandas PASTIS-equivalentes**: PASTIS-R usa 10 bandas en orden
   `[B02,B03,B04,B05,B06,B07,B08,B8A,B11,B12]` (B4 red idx2, B8 idx6 — el contrato que
   TSViT/U-TAE esperan). El adapter selecciona estas 10 de las 13 de Sen4AgriNet (descarta
   B01,B09,B10 de 60 m). **Verificar el orden exacto de bandas PASTIS** contra
   `ml/ingest/pastis_loader.py`/`pastis_dataset.py` al implementar (band order es load-bearing
   para que los pesos FR apliquen).
3. **Binning mensual** identico al oficial: `groupby_bins('1M').median` -> `resample('1M').median`
   -> `interpolate_na(linear, extrapolate)`. Resultado `(12, 10, H, W)`.
4. **Upsample 20/60 m -> 10 m** con `np.repeat(expand_ratio)` (las 6 bandas de 20 m a 366x366).
5. **Subsample temporal a `n_timesteps`** del modelo (TSViT-pheno = 10) con
   `_equispaced_indices` (reutilizar el helper de `pastis_seg_dataset.py`) -> `(T, 10, H, W)`.
   Alternativa: pasar los 12 meses si el modelo se reentrenara con n_timesteps=12; se elige
   T=10 para alinear con el checkpoint FR (el PE ordinal de TSViT se entreno con T=10).
6. **Normalizacion** `/10000` -> `[0,1]` (igual a PASTIS sin per-fold stats; opcionalmente
   aplicar las stats de train FR para que la entrada caiga en el dominio del checkpoint).
7. **Crop/resize espacial**: el patch Sen4AgriNet es 366x366; PASTIS es 128x128. El adapter
   genera sub-patches 128x128 (center-crop o tiling como `requires_subpatching` del oficial)
   o resamplea a 128 (nearest para labels, bilinear para bandas) para que las dimensiones del
   modelo cuadren. Decision: **tiling a 128** (preserva resolucion nativa; mas patches para
   few-shot). Documentar la eleccion.
8. **linear_encoder + remapeo HCAT**: dos pasos:
   - (a) FAO-ICC crop id -> macro HCAT (via `hcat_crosswalk`): p.ej. `110 Wheat -> cereals`,
     `120 Maize -> cereals`, `140 Sorghum -> cereals`, `330 Grapes -> vineyard`,
     `435 Rapeseed -> oilseed_industrial`, `510 Potatoes -> potato`, `770 Peas -> legumes_fodder`.
   - (b) macro HCAT -> id contiguo del label-space comun (mismo que se usa para evaluar FR).
   - `background (0)` y crops fuera del nomenclator -> `ignore_index` (255), convencion
     homogenea US-074.

> **Espacio de evaluacion del Delta mIoU**: para comparar FR (PASTIS-18) y ES (Sen4AgriNet)
> apples-to-apples, ambos se proyectan al **label-space HCAT macro** (10 grupos + void). El
> modelo FR predice en su espacio 18-clase nativo; sus logits/argmax se agregan a macro HCAT
> con el crosswalk (suma de probabilidad por grupo o argmax->grupo). El target Sen4AgriNet ya
> esta en macro HCAT. Esto evita el conflicto "Sorghum/olivo no existe en PASTIS-FR": esas
> clases ES nuevas viven en su macro HCAT (cereals/permanent_woody) y el few-shot las aprende.

### 3.3 Finetune denso FR -> Catalonia (en la VM H100)

`ml/train/finetune_sen4agrinet.py` (o celdas en el notebook que invocan `train_segmentation`):

1. **Cargar checkpoint FR**: `tsvit-pheno-v1/best.pt` -> `build_tsvit(num_classes=N_MACRO, ...)`
   + `load_state_dict(..., strict=False)`. Si el head FR es 18-clase y el target es N_MACRO
   (10), se **reinicializa solo el head** (`to_seg`/`out_conv`) y se cargan el resto de pesos
   (encoder temporal+espacial FR frozen o con LR menor). Documentar la estrategia de
   congelado: **few-shot = encoder con LR bajo (1e-5) + head nuevo con LR normal (1e-4)**, o
   linear-probe (encoder frozen, solo head) como variante mas barata.
2. **Splits**: Catalonia patches -> train few-shot (k patches) + val held-out. Reportar k
   (p.ej. 10-shot, 50-shot). FR patches -> referencia zero-shot.
3. **Zero-shot eval** (ANTES de finetune): aplicar el checkpoint FR (proyectado a macro HCAT)
   sobre el val Catalonia -> `mIoU_zero_shot`. Esto SIEMPRE se puede reportar (no requiere
   convergencia), es el plan B minimo.
4. **Few-shot finetune**: `train_segmentation(model, train_cat_ds, val_cat_ds, lr=1e-5...,
   epochs=N, mlflow_run_name="ft-sen4agrinet-tsvit-pheno", ...)` con MLflow
   (`data_version`=DVC del subset, `code_version`=git SHA). -> `best.pt` Franco-Iberico.
5. **Few-shot eval**: aplicar el modelo finetuneado sobre el mismo val Catalonia -> `mIoU_few_shot`.
6. **Delta mIoU** = `mIoU_few_shot - mIoU_zero_shot` = magnitud del domain gap recuperado.

> **VRAM**: H100 NVL con 74 GB libres (Qwen usa 21 GB en :8002). TSViT-pheno n_timesteps=10
> en 128x128 cabe holgado (el train original corrio en L4 24 GB). U-TAE aun mas ligero.

### 3.4 Delta mIoU — protocolo exacto

```
acc_zs = DenseConfusionAccumulator(N_MACRO, ignore_index=255)
acc_fs = DenseConfusionAccumulator(N_MACRO, ignore_index=255)
for x, y in val_cat_loader:          # y = target macro-HCAT de Catalonia (real)
    pred_zs_18 = predict_patch_for_kind(model_fr, x, model_kind="tsvit-pheno")
    pred_zs_macro = project_18_to_macro(pred_zs_18)   # crosswalk
    acc_zs.update(pred_zs_macro, y)
    pred_fs_macro = predict_patch_for_kind(model_ft, x, model_kind="tsvit-pheno")  # head macro
    acc_fs.update(pred_fs_macro, y)
miou_zero_shot = acc_zs.compute()["miou"]
miou_few_shot  = acc_fs.compute()["miou"]
delta_miou = miou_few_shot - miou_zero_shot
```

El mIoU se computa SOLO sobre patches Catalonia REALES descargados. Si solo bajan M patches,
se reporta `n_patches=M` honestamente.

## 9. Caveat de transferibilidad (honesto, AC-5)

AlphaEarth (`SATELLITE_EMBEDDING/V1/ANNUAL`) tiene **transferibilidad espacial limitada**
(arXiv:2601.00857): los embeddings entrenados en una region no transfieren zero-shot a otra
geografia con la misma fidelidad. Por eso US-075 **presupuesta few-shot finetune** y reporta el
**Delta mIoU** como evidencia cuantitativa del domain gap, **NO promete zero-shot**. El resultado
esperado y honesto es: `mIoU_zero_shot` bajo (el modelo FR no generaliza a Iberia sin adaptacion)
y `mIoU_few_shot` mayor (el few-shot recupera buena parte del gap). El Delta ES el entregable
cientifico, no un numero de accuracy alto. Aplica tanto al camino denso (TSViT/U-TAE, esta US)
como al few-shot tabular AlphaEarth+XGB de US-076.
