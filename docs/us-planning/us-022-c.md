## 11. Riesgos y mitigaciones

| ID | Riesgo | Probabilidad | Impacto | Mitigacion |
|----|--------|-------------|---------|------------|
| R1 | Spot L4 preempted en mid-training FarSLIP | media | medio | `restartJobOnWorkerRestart: false` + checkpoint cada 30 min a `gs://agrosat-artifacts-dev/vertex-jobs/farslip/` + reanudacion manual con `gcloud ai custom-jobs create --resume` |
| R2 | mIoU FarSLIP - mIoU RemoteCLIP < +0.05 (gate B-3 falla) | media | bajo | **Aceptable** (R6 del plan US-022b). Documentar resultado negativo honesto en `docs/us-resolved/us-022-c.md`. La US cierra igual; impacto: FarSLIP queda como base learner opcional del stacking ensemble EPIC 6 |
| R3 | Costo L4 > $5 USD por bug de timeout | baja | alto | Cap duro `timeoutSeconds: 14400` (4h) en `ml/configs/l4_spot.yaml` ya configurado + `make cost-audit` antes y despues + gate FinOps en `scripts/cost_audit.sh` |
| R4 | F1 temporal sigue bajo (< 0.20) despues de los 4 fixes ML | media | medio | **Aceptable y reportable.** Documentar como hallazgo honesto + hipotesis (FFT reconstruccion vs serie diaria real). Crear backlog `us-022-d-temporal-daily-series.md` para EPIC 5 si el equipo decide investigar |
| R5 | `terraform import tfstate` falla por permisos / lifecycle conflict | baja | bajo | Verificar que el bucket existe + grant `storage.admin` temporal al SA de CI + revisar `lifecycle_rule` declarada (30 versions max) coincide con la del bucket real. Si conflict, ajustar HCL antes del import |
| R6 | EuroCrops FR (11 GB) excede cuota DVC bucket dev | baja | medio | Verificar capacidad de `gs://agrosat-dvc-remote` (>= 50 GB libre); si no, comprar/expandir bucket (~$0.02/GB/mes en STANDARD) o usar storage class NEARLINE para datasets readonly |
| R7 | Cache Gemini hit < 90 % en P5 (recosto) | baja | bajo | Cache por hash NDVI ya implementado (`ml/features/phenology_description.py:_cache_key`). Subset 216 parcelas = 216 API calls maximo. Budget hard cap $0.20 documentado |
| R8 | El re-ejecutado del notebook 05 sobreescribe outputs validados de US-022b sin git history | baja | bajo | Antes de ejecutar P3: `git stash` el .ipynb actual + commit del "before" si discrepa significativamente. Usar timestamp en cell metadata |
