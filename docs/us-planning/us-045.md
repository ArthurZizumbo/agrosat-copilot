## 2. Arquitectura de la solucion

```
                  google-genai loop (US-047)
                          |
                  FunctionDeclaration[9]   <- build_function_declarations()
                          |
        +-----------------+------------------+
        | ml/agent/tools.py  (orquestador)   |
        | TOOL_REGISTRY: dict[str, ToolSpec] |
        +-----------------+------------------+
                          |
   +----------+-----------+-----------+-----------+
   |          |           |           |           |
ml/agent/tools/  (un helper por tool, write-set disjunto)
 parcels.py  timeseries.py  aoi_stats.py  stac.py  tiles.py
 classify.py  add_aoi.py  compare.py  explain.py
   |          |           |           |
   v          v           v           v
 asyncpg    asyncpg     GEE/XGB    pgstac/STAC  TiTiler
 (RLS)      (RLS)       ensemble   (diferida)   (diferida)
```

**Capas:**
- `ml/agent/schemas.py` — Pydantic `ToolInput`/`ToolOutput` + tipos compartidos (`GeoJSONGeometry`, `BBox`, `ParcelRef`).
- `ml/agent/db.py` — pool asyncpg + helper `session_scoped_conn(session_id)` que hace `SET LOCAL` (RLS).
- `ml/agent/tools/*.py` — un modulo por tool, funcion async pura `async def run(inp: ToolInput, ctx: ToolContext) -> ToolOutput`.
- `ml/agent/tools.py` — registro central `ToolSpec(name, fn, input_model, output_model, deferred, declaration)` + `build_function_declarations()`.

**RLS (AC-3):** la migracion de RLS por `session_id` vive en EPIC 11 (no es de esta US). Mientras tanto, las tools filtran por `session_id` en el WHERE Y ejecutan `SET LOCAL app.current_session = $1` para dejar el hook listo cuando la policy RLS exista. El helper `session_scoped_conn` centraliza ambos.

## 9. Riesgos y mitigaciones

| Riesgo | Mitigacion |
|--------|------------|
| RLS policy no existe aun (EPIC 11) | `session_scoped_conn` deja el `SET LOCAL` listo + filtro `WHERE session_id` explicito como defensa en profundidad. |
| pgstac/TiTiler no desplegados | `search_stac`/`get_tiles` marcadas `deferred=True`; devuelven `NotConfigured` controlado si falta el backend, no crashean. |
| Carga de checkpoints lenta en cada call | LRU cache del ensamble cargado (`functools.lru_cache` sobre el loader). |
| `google-genai` API de FunctionDeclaration cambia | Pin de version en lock; `build_function_declarations` aislado para un solo punto de cambio. |
