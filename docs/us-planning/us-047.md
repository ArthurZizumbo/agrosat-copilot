## 2. Arquitectura

```
  ChatService (US-046)  ->  Agent.stream_response(messages, session_id)
                                |
                                v
                    ml/agent/agent.py: Agent
                      - backend: LLMBackend (inyectado por create_agent)
                      - tools: list[ToolSpec] (de TOOL_REGISTRY, US-045)
                      - instruction: system prompt analista (prompts.py)
                                |
            loop manual de function calling (automatic disabled):
              1. backend.generate(contents, tools_decl, system) -> function_calls | text
              2. por cada function_call: ejecutar ToolSpec.fn(input_model(**args), ctx)  [RLS via ctx]
                 emitir tool_call + tool_result
              3. devolver FunctionResponse al backend, repetir hasta texto final
              4. emitir text_delta(s) + done
                                |
            +-------------------+--------------------+
            | GeminiBackend          | VLLMOpenAIBackend       |
            | google-genai client    | OpenAI-compat (Qwen)    |
            | gemini-2.5-pro/flash    | http://host/v1 (US-048) |
            +------------------------+-------------------------+
```

## 4. Interfaces publicas

```python
# ml/agent/backends.py
class LLMBackend(ABC):
    @abstractmethod
    async def generate_stream(self, *, contents: list, tools: list,
                              system_instruction: str) -> AsyncIterator[BackendChunk]: ...
    # BackendChunk: text delta | function_call(name, args, id) | done

class GeminiBackend(LLMBackend):
    def __init__(self, model: str = "gemini-2.5-pro", client: genai.Client | None = None): ...
class VLLMOpenAIBackend(LLMBackend):
    def __init__(self, base_url: str, model: str, api_key: str = "EMPTY"): ...

def make_backend(model: str, settings: Settings) -> LLMBackend: ...  # 'gemini*'->Gemini, 'qwen*'->vLLM

# ml/agent/agent.py
class Agent:
    backend: LLMBackend
    tools: list[ToolSpec]
    instruction: str
    async def stream_response(self, messages: list[dict], session_id: UUID,
                              ctx: ToolContext) -> AsyncIterator[AgentEvent]: ...

def create_agent(model: str = "gemini-2.5-pro",
                 tools: list[ToolSpec] | None = None,   # default: get_sync_tools()
                 instruction: str = ANALYST_SYSTEM_PROMPT,
                 settings: Settings | None = None) -> Agent: ...
```

## 9. Riesgos y mitigaciones

| Riesgo | Mitigacion |
|--------|------------|
| google-genai automatic function calling no encaja con tools async + ToolContext | Deshabilitar automatic (`AutomaticFunctionCallingConfig(disable=True)`), loop manual: leer `response.function_calls`, ejecutar con ctx, devolver `FunctionResponse`. |
| Qwen on-prem no disponible (US-048 bloqueado) | `VLLMOpenAIBackend` se implementa y testea con mock; el switch a Qwen funciona en cuanto el endpoint exista. Gemini default no se afecta. |
| `get_settings()` rompe en tests (.env.local extra=forbid) | Inyectar `settings` stub en `create_agent`/`Agent` (patron de US-045/046). |
| Args del function_call mal tipados | Validar con el `input_model` Pydantic del ToolSpec antes de ejecutar (rechaza args invalidos). |
