Cerrar el criterio "Riesgos" (20 pts) de la rubrica del Avance 7 con un documento unico,

### 3.0 Metodologia (seccion 0)

- Escala de **probabilidad**: Alta (esperable en el horizonte del proyecto), Media (plausible
  bajo ciertas condiciones), Baja (poco probable pero con impacto a considerar).
- Escala de **impacto**: Alto (bloquea entregable / fuga de datos / incumplimiento legal),
  Medio (degrada calidad o cronograma sin bloquear), Bajo (molestia o coste menor).
- **Severidad** = funcion Prob x Impacto, usada para ordenar la matriz y el top-5.
- Fuentes declaradas: plan v8 (§4 Gestion de Riesgos, §5 Criterios de exito), `docs/STATUS.md`,
  ADR-009, blockers de EPIC 10/12, resultados E12 cerrados (US-075/076/077), memoria del proyecto.

Cada fila: id, riesgo, probabilidad, impacto, mitigacion accionable. Cubre como minimo los
items nombrados en el AC:

| id | Riesgo | Notas de realidad (fuente) |
|----|--------|----------------------------|
| R-DAT-01 | Disponibilidad / caidas de CDSE (Copernicus Data Space Ecosystem) | Mitigacion: GEE AlphaEarth como fuente primaria (no depende de CDSE para embeddings); reintentos + cache COG |
| R-DAT-02 | Calidad de labels (PASTIS-R, partial-label / null-class del crosswalk HCAT) | US-074 ya trata clases fuera del crosswalk como `null-class`, no error duro |
| R-DAT-03 | Cobertura de nubes en Sentinel-2 | Mediana temporal anual / compositing; AlphaEarth ya agrega anualmente |
| R-DAT-04 | **Transferibilidad espacial limitada de AlphaEarth** (arXiv:2601.00857) | Evidencia REAL E12: Sen4AgriNet FR->Catalonia zero-shot mIoU 0.0000, few-shot 0.2468 (Delta +0.2468) -> el gap espacial existe y se cierra con few-shot, NO con zero-shot |
| R-DAT-05 | Descarga lenta/fallida de subsets multi-region (Sen4AgriNet ~943 MB, EuroCropsML ~GB via Zenodo) | Plan B escalonado (subset minimo) ya documentado en blockers E12; versionado DVC |
