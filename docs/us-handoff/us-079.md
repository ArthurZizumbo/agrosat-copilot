## Decisiones tecnicas clave
- Kept-class flag como ARRAY de clases conservadas (IT leaf -> PASTIS class name);
  filas warm-start, nuevas random. Generalizacion de `warm_start_head` a Italia.
- Split ESPACIAL con los folds del metadata de US-078 (nunca random).
- Voting-3 aprende pesos sobre preds post-softmax de validacion IT (anti-fuga, OOF).
- Objetivo de calidad: F1-macro > 0.9 sobre las ~10 clases mejor resueltas (espejo
  del 0.9069 france-10 / 0.92 france-9 del Voting-3 en PASTIS).

## Decisiones tecnicas tomadas en la implementacion (codigo)
- **Voting-3 = TSViT-pheno + U-TAE + TSViT-pheno-fullm**. La terna PASTIS del
  campeon es `tsvit-pheno + utae + xgb-alphaearth`, pero `xgb-alphaearth` exige un
  embedding AlphaEarth por parcela NO materializado para Italia; el tercer miembro
  denso natural es el TSViT Full-M (otro checkpoint PASTIS real, fine-tuneable). El
  adaptador es agnostico al numero de miembros: si se materializa xgb-alphaearth se
  cambia con un flag `--members`.
- **TSViT warm-start = cls-tokens, no `to_seg`**. En TSViT-pheno-v1 (L4, dim=128,
  depth 4+4, n_timesteps=10, F1 0.75 PASTIS) la "cabeza por clase" es el banco de
  `temporal_cls_tokens (1,18,128)`; `to_seg (64,128)` es compartido (se copia
  verbatim). Se warm-startean las 20 filas de cls-tokens de las clases conservadas.
  (En `finetune_baltico` TSViT NO warm-starteaba cabeza: aqui SI, generalizado.)
- **U-TAE id namespace = semantic_id + 1** (id 0 background, 19 void en la cabeza
  20-cls de Isaac); el warm-start mapea las clases conservadas a las filas 1..18.
- **Label-space denso con background** (40 clases = bg + 39 crops) para alinear el
  eje de clases del modelo 1:1 con las mascaras `TARGET_<id>.npy` en disco;
  background excluido de loss y metricas (ignore_index=0).
- **Voting OOF por fold espacial**: leave-one-spatial-fold-out a nivel patch sobre
  las preds densas IT (anti-fuga). NOTA OPERATIVA: con `test_fold` aislando 1 solo
  fold, el voting no puede CV (degrada con gracia + warning honesto). Con el dataset
  COMPLETO el test debe abarcar >=2 folds espaciales (elegir el fold de test que
  agrupe varios super-cells, o reservar varios folds de eval) para que los 3 pesos
  se aprendan OOF de verdad.
