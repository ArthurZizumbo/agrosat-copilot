## Resumen ejecutivo

Producir y **endurecer** los prototipos fenologicos por clase: curva NDVI media por clase (18 cultivos
PASTIS-R) -> descripcion textual **ES** via Gemini Flash (temperature=0, cache SHA256, Wen et al. 2025) ->
embedding **MiniLM 384-dim** (sentence-transformers frozen). Output:
`data/features/phenology_class_prototypes_pastis.parquet` (18 filas: `class_id`, descripcion ES,
`emb_000..emb_383`), reutilizando `ml/features/phenology_description.py`. La **variante por-parcela**
(descripcion individual segun curva NDVI real, cacheada por `parcel_id`) queda explicitamente expuesta y
documentada. **El parquet y la variante YA EXISTEN y estan DVC-trackeados; NO se regeneran.**

## Logica de los prototipos (resumen)

```
compute_class_mean_ndvi_curves(PASTIS-R) -> {1..18 -> curva NDVI media (37 bins DOY)}
for c in 1..18:
    desc[c] = generate_phenology_description(curva[c], parcel_id=f"class_{c}",
                  crop_type_hint=class_name[c], model="gemini-3.5-flash", temperature=0.0)
              # cache HIT por SHA256(parcel_id+curve+model+"prompt_v1")[:16] -> NO LLM
emb = _encode_descriptions(desc) -> (18, 384) float32 L2-norm (MiniLM frozen)
-> parquet (18 filas: class_id, class_name, ndvi_curve, description, emb_000..emb_383)
```

Golden values (verificados en disco): parquet `(18, 388)`; `class_id==[1..18]`; desc lens
`[807,586,686,870,717,733,671,646,726,766,636,584,651,810,799,666,723,594]` (todas >50); `abs(emb).sum()`
por fila ~15.5 (>0). Variante por-parcela: `phenology_text_pastis.parquet` `(1080, 386)`, 1080 `parcel_id`
unicos.

## Riesgos principales

1. **R-KEY (riesgo #1)**: GEMINI_API_KEY autorizada solo como cache -> no generar texto nuevo. Mitigacion:
   **NO regenerar**; parquet + ~1968 descripciones cacheadas ya poblados con outputs reales; tests con
   `set_llm_client(mock)` (cero red); `encode_descriptions` offline. Comando de regeneracion documentado
   para cuando haya key valida.
2. **R-DVC**: regenerar/sobrescribir el parquet a ciegas cambia el md5 del `.dvc` y los embeddings -> rompe
   `PhenoSemanticBranch` y `test_dense_metrics.py`/`test_pheno_semantic_branch.py`. Mitigacion: "No tocar"
   `data/features/*`; tests en `tmp_path`; DRY opcional solo si bit-identico.
3. **R-DETERM (gap #1)**: falta el test de determinismo per-clase (tarea tecnica v8 linea 1218). Mitigacion:
   `test_generate_class_prototypes_deterministic_two_runs` (dos corridas mock -> parquet identico + 2.a
   cache-hit). Entregable central.
4. **R-VARIANTE**: cual parquet es la variante por-parcela. Es `phenology_text_pastis.parquet` (no las
   anclas `pastis_phenology_anchors_2019.parquet`). Test AC-7 lo fija.
5. **R-MODEL**: default `gemini-3.5-flash` vs CLAUDE.md "Gemini 2.5 Pro". El parquet es coherente con
   3.5-flash (model en cache key). NO cambiar sin coordinar; confirmar en review.
