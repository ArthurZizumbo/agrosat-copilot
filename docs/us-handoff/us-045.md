## Decisiones tecnicas (fijadas en planeacion)

- DB ya existe (`parcels`, `aois`, `features_parcels` con `alphaearth_embedding VECTOR(64)`, `ndvi_stats`/`phenology` JSONB). Acceso via **asyncpg** directo (no hay SQLModel ORM).
- RLS policy es EPIC 11: las tools dejan `SET LOCAL app.current_session` + filtro `WHERE session_id` (defensa en profundidad) via `session_scoped_conn`.
- `classify_new_parcel` sobre una parcela NUEVA usa la ruta **xgb-alphaearth** (embedding 64-dim -> XGBoost): es la unica inferencia directa por-parcela; los segmentadores densos (tsvit/utae) necesitan raster temporal y van por OOF/Pub/Sub. `compare_models` compara las predicciones ya dumpeadas (OOF parquets) de los miembros.
- `explain_prediction` emite TEXTO estructurado (cultivo, fenologia, vigor, confianza) reutilizando `generate_phenology_description` -> entrada del patron Be My Eyes (US-046).
- 5 tools sync (demo) + 4 deferred (`search_stac`, `get_tiles`, `add_aoi`, `compare_models`).
- SDK `google-genai` para `FunctionDeclaration` (NO google-adk).

## Bugs / bloqueos

- **Fix aplicado:** `GeoJSONGeometry._ALLOWED_TYPES` debia ser `ClassVar[frozenset[str]]` (Pydantic v2 lo trataba como `ModelPrivateAttr` -> `TypeError` al construir cualquier geometria). Corregido en `ml/agent/schemas.py`.
- **Nota para US-046/047:** `get_settings()` real NO se puede llamar en tests (el `.env.local` dev tiene llaves que `Settings(extra="forbid")` rechaza). Los tests usan `FakeSettings`. Relevante para el loop del agente.
- **compare_models:** un `parcel_id:int` plano no matchea los OOF (ids compuestos `patch_local`, ej. `10003_1103071`). Camino vacio honesto cubierto.
