## Resumen ejecutivo

Construir la **infraestructura nueva** del protocolo incremental n-clase sobre PASTIS-R real y validarla con un
**POC de 2 epochs por stage**. Stage-1: 4 clases `[Meadow=1, Soft winter wheat=2, Corn=3, Grapevine=8]`, patches
3:1, 4 prototipos. Stage-2: 18 clases full, init `student.load_state_dict(stage1, strict=False)`, 18 prototipos.
El `strict=False` transfiere los PESOS DEL ENCODER (student ViT), NO los prototipos (esos viven fuera del
`state_dict` y se reconstruyen por stage). Imagen del par = composite pico-NDVI del patch (4 bandas); clase =
dominante del patch. Entregable: dataset builder + orquestador + tests + POC corrido con tabla de convergencia y
**fallback honesto** (si Stage-2 degrada vs un control from-scratch, entrenar 18-clase desde cero).

```

  peak_ndvi_composite: t*=argmax mean(NDVI_t); img4 = s2[t*, [B02,B03,B04,B08]] /10000 -> 224
  dominant_class(semantic, active) -> category_id en [0,n-1]   (excluye 0/19; None -> patch fuera)
```

## Riesgos principales

1. **R-STRICT**: `strict=False` silencioso (encoder NO transferido). Mitigacion: test de igualdad de pesos +
   log de `missing/unexpected_keys`.
2. **R-CONV**: Stage-1 con set pequeno (4 clases + 3:1) puede no converger en 2ep. Mitigacion: el POC mide
   mecanica, no SOTA; gate `loss_cls` epoch1<epoch0 y <`ln(4)`; subir folds si hace falta.
3. **R-NDVI**: composite pico-NDVI con timesteps nublados (PASTIS no enmascara nubes). Mitigacion: clamp NDVI a
   [-1,1], `nanmean`; documentar (US-036-a puede anadir QA).
4. **R-DOM**: clase dominante en patch mixto. Mitigacion: filtro 3:1 ya descarta Meadow-dominados; patch sin
   clase activa se EXCLUYE (no etiqueta espuria).
5. **R-SYNTH**: regresion al error italiano sintetico. Mitigacion: `PastisPairDataset` independiente; sin
   referencias a `farslip_pairs`/`_synthetic_crop` en el path productivo.
6. **R-DEGRADE**: Stage-2 degrada vs from-scratch -> fallback honesto (18-clase desde cero), gate `warm <=
   from-scratch + 0.05`.
