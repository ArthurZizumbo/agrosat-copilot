## Desviaciones del plan

1. **`run_name` y `mlflow_uri` como parametros de `run_incremental_curriculum`**: el plan (Seccion 4.2) no los
   lista en la firma, pero el orquestador los necesita para nombrar runs por escalon y apuntar a `:5010`/SQLite
   (CI). Defaults `farslip-full-incr` y `http://localhost:5010`. Sin impacto en contratos.
2. **`max_classes` como parametro** (default 18): permite curriculums truncados para diagnostico/CI sin tocar
   codigo; alineado con `stop_criterion(max_classes=...)`.
3. **Floor productivo `epochs_per_step >= 20`**: el orquestador RECHAZA con ValueError epochs < 20 (AC-6: "N
   epochs hasta convergencia, NO el smoke de 2"). Endurece el AC en codigo.
4. **`_log_step_run` es un run MLflow SEPARADO del trainer**: el trainer (`distill.py`) abre/cierra su propio
   run por la curva de loss; el orquestador NO puede inyectar metricas por clase en ese run sin tocar
   `distill.py` (prohibido). Por eso loggea un run adicional por escalon con `f1_class_*`/`iou_class_*`/
   `macro_f1`/tabla por clase + tags `data_version`/`code_version`/`us=US-036-a`. Resultado: 2 runs por escalon
   (loss del trainer + per-class del orquestador), ambos CERRADOS y bajo el mismo `run_name`/experiment
   `farslip`. Test `test_log_step_run_closes_run` verifica status FINISHED (gotcha RUNNING de ml/AGENTS.md).
5. **Winner por `n_classes_well_resolved` (tie -> macro-F1)** en `_select_winner`: el plan habla de "escalon con
   mejor convergencia"; se concreta a "mas clases bien resueltas (F1>=0.50), desempate por macro-F1" — la
   metrica honesta que la rubrica premia ("se resuelven bien hasta N clases").

## Escalones del curriculum (propuesta + justificacion)

**Ranking de cardinalidad (EDA "Cardinalidad de cultivos PASTIS", n_pixels mayor->menor; IDs PASTIS 20-clase)**:

```
1 Meadow(1) ~20.2k | 2 Corn(3) ~8k | 3 Soft winter wheat(2) ~6k | 4 Grapevine(8) ~5.3k   <- ESCALON 0 (4 dominantes)
5 Winter barley(4) | 6 Leguminous fodder(14) | 7 Winter rapeseed(5) | 8 Orchard(16)
9 Winter triticale(10) | 10 Spring barley(6) | 11 Soybeans(15) | 12 Sunflower(7)
13 Winter durum wheat(11) | 14 Beet(9) | 15 Fruits/veg/flowers(12) | 16 Mixed cereal(17)
17 Potatoes(13) | 18 Sorghum(18)                                                          <- cola (<200px)
```

`cardinality_ranking()` golden = `[1,3,2,8,4,14,5,16,10,6,15,7,11,9,12,17,13,18]`.

**Esquema recomendado: `+2` por escalon a partir de 4** -> `4 -> 6 -> 8 -> 10 -> 12 -> 14 -> 16 -> 18`
(8 escalones, objetivo 18). **Justificacion**: (a) paso fino localiza con precision el escalon donde la
convergencia se rompe (criterio de parada), que un salto +4 ocultaria; (b) anadir solo 2 clases minimiza el
shock de distribucion para el init encadenado (currículum learning suave); (c) las clases cola (<200 px:
Sorghum 18, Potatoes 13, Mixed cereal 17) entran aisladas al final, donde es mas probable que disparen la
parada sin contaminar el diagnostico de las clases medias.

**Plan B (presupuesto H100 ajustado): `4 -> 8 -> 12 -> 18`** (4 escalones, +4). El esquema es PARAMETRO
(`step_size`), no codigo: cambiar de +2 a +4 es config.

**Criterio de parada** (`stop_criterion`): (1) 18 clases convergidas (`max_classes_reached`, exito); (2)
macro-F1 de clases previas cae > 0.05 absoluto (`prev_classes_degraded`); (3) ninguna clase NUEVA con F1>=0.30
(`new_classes_unacceptable`); (4) presupuesto agotado (`budget_exhausted`). Se reporta el ultimo escalon sano.

## Logica del curriculum (resumen)

```
ranking = cardinality_ranking()                     # [1,3,2,8,4,14,5,16,10,6,15,7,11,9,12,17,13,18]
proto_18, ids_all = load_class_prototype_embeddings()   # (18,384), Gemini real US-033 (DVC, solo LEER)
best_prev = None
for k, n in enumerate([4,6,8,10,12,14,16,18]):      # +2 por escalon (o [4,8,12,18] plan B)
    ids   = class_ids_for_step(k, step_size=2, base=4)        # primeras n del ranking
    ds    = create_incremental_dataset(n_classes=n)          # US-036 (IMPORTADO), PASTIS real, filtro 3:1
    proto = select_step_prototypes(proto_18, ids_all, ids)    # (n,384), n_regions=1, PASTIS directo
    cfg   = FarSLIPTrainerConfig(n_regions=1, n_categories=n, n_in_channels=4, n_epochs=M,
                                 mlflow_run_name=f"farslip-full-incr-{n:02d}cls", ...)
    tr    = FarSLIPDistillationTrainer(cfg, dataset=ds)
    if best_prev: tr.student.load_state_dict(load(best_prev), strict=False)   # init encadenado
    tr.set_text_prototypes(proto)                            # reproyecta (n,384)->(n,768)
    tr.train()                                               # M epochs hasta convergencia
    best_k  = save -> checkpoints/farslip/incremental/{n:02d}cls/best.safetensors
    metrics = eval_per_class(student_k, ds_val, ids)         # F1/IoU por clase
    log_run(MLflow :5010, n_classes=n, metrics, loss curve)
    stop, reason = stop_criterion(metrics, metrics_prev)
    if stop: break
    best_prev = best_k
best_winner -> dvc add + dvc push (desde la VM, ADC OK)      # insumo de US-037
```
