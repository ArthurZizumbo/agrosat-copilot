## Decisiones tecnicas clave
- Layout de salida ESPEJO de PASTIS: `S2_<id>.npy (T,10,128,128)` +
  `TARGET_<id>.npy (128,128) int32` + `dates_<id>.npy (DOY)` + `metadata.parquet`.
- 10 m/px nativo S2 (= PASTIS); pedir mas fino solo upsamplea (verificado, std identico).
- Mascara: rasterizar con `rasterio.features.rasterize` usando el transform del tile SH
  (mismo grid que la imagen) — NO un transform from_bounds independiente, para garantizar
  alineacion pixel-perfect imagen<->mascara. Geometrias son MultiPolygon (usar .geoms).
- id 0 = fondo/no-cultivo. Clases <MIN_SUPPORT parcelas -> "other" (no inflar label-space).
- Fold espacial en metadata (para CV sin fuga en US-079).
