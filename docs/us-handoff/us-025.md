## Decisiones técnicas y gotchas

- **API smp 0.5**: no tiene `mobilenet_v3_large` nativo → se usa `tu-mobilenetv3_large_100` (timm-universal). Firma pública sin cambios. 1ª ejecución descarga ~21MB HF.
- **Cobertura resuelta**: 18 prototipos por-clase (100%) en vez de 1080 por-parcela (0.72%). Fiel al paper (Fig. 2/6).
- **Prototipos como anclas fijas**: el training loop los pasa detached (setup zero-shot estilo CLIP). El `proj` de `PhenoSemanticBranch` no se entrena en este setup → evita doble-backward.
- **Bug arreglado** (tests lo revelaron): `DiceCrossEntropyLoss` daba NaN cuando un patch es todo `ignore_index` → `torch.nan_to_num` preservando grafo.
- **Gotcha entorno**: `poetry run python -c "<largo>"` pierde stdout; usar scripts a archivo. `metadata.geojson` con `json.load` no geopandas.
- **einops** estaba en pyproject pero no instalado en el venv → reinstalado.
