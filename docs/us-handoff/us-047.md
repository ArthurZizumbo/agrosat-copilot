### Caveats honestos

- `backends.py` 67% cobertura: los paths de streaming real (GeminiBackend `generate_content`/stream, OllamaBackend reasoning) no son unit-testeables sin LLM en vivo; la logica de mapeo si esta testeada.
- `prompts.py` 0% en el coverage de tools: es una constante string; se consume en el loop del agente (cubierto por agent.py).
- Exceptions pre-loop: el guard de error es ultimo recurso; excepciones antes del loop no se capturan dentro de `stream_response`.
- `GeminiBackend` usa API no-stream para function_calls + stream para texto (superficie canonica); soporta cliente async y sync (test doubles).
