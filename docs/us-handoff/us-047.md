- `ml/agent/agent.py` — `Agent` + `create_agent()` + `stream_response()`. Loop manual de function calling (MAX_TURNS=8), inyecta `session_id` en cada tool, valida args con el input_model Pydantic, emite AgentEvent. Default tools = get_sync_tools() (5 demo).
- `ml/agent/backends.py` — `LLMBackend` ABC, `GeminiBackend` (google-genai, automatic FC disabled, non-stream para calls + stream para texto), `VLLMOpenAIBackend` (OpenAI-compat para Qwen US-048, mapea genai.Content<->OpenAI messages), `make_backend(model, settings)`. BackendChunk(.text, .function_call).
- `ml/agent/prompts.py` — `ANALYST_SYSTEM_PROMPT` (analista agronomico, Be My Eyes, citas obligatorias, no alucina).
- `ml/agent/events.py` — AgentEvent (ToolCallEvent, ToolResultEvent, TextDeltaEvent, PerceiverObservationEvent, DoneEvent, ErrorEvent) con campo `type` discriminante.
- `backend/app/services/chat_service.py` — cablea el agente REAL: emite perceiver_observation, luego reenvia los AgentEvent del agente (tool_call/tool_result/text_delta/done/error) por SSE.
- Tests: `tests/ml/agent/test_agent.py`, `test_backends.py`, `backend/tests/unit/test_chat_sse.py`.
