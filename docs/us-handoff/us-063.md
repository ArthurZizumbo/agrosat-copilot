## Que entrega US-063

Documento de decision multi-cloud `docs/cloud/comparativa_proveedores.md` que justifica la
arquitectura **GCP primario + H100 NVL 96GB del sponsor (Azure / on-prem) para training intensivo y
serving Qwen vLLM**, comparando como minimo GCP vs Azure (AWS e IBM Cloud como referencia opcional)
sobre **cinco factores tecnicos**: (1) precio GPU H100 on-demand y spot, (2) ecosistema de Earth
Observation (GEE vs Planetary Computer vs AWS Open Data), (3) latencia hacia Europa con target
Italia, (4) soporte de pipelines MLOps (Vertex AI Pipelines vs Azure ML vs SageMaker), (5)
partnerships academicos / creditos. Cubre el criterio "Implementacion" (30 pts) del Avance 6:
exhibir >=2 proveedores y argumentar la eleccion con datos REALES del proyecto, no benchmarks
genericos inventados.

- **Factor 3 latencia Italia** (AC-5): GCP `europe-west8` (Milan) para el path latency-sensible

  SageMaker.
- **Factor 5 partnerships** (AC-7): incluye el **caveat obligatorio** — el "Trial credit for GenAI
  App Builder" ($17,178) es de Vertex AI Search / Agent Builder y **NO cubre** la SKU de generacion

- **Decision justificada** (AC-8): GCP primario + H100 sponsor + narrativa de soberania de datos
  (Qwen3.5-35B-A3B vLLM GPTQ-Int4 on-prem); Gemma 4 LoRA OUT (ADR-009 future).
- **Realidad v8** (AC-9): el doc afirma explicitamente H100 **activa 24/7, NO parked**; el bloque
