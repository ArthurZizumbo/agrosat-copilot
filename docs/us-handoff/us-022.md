## Decisiones tecnicas clave (planning)

1. **El escenario (b) Sentinel-2 crudo se GENERA** — no existe en el repo (verificado 2026-05-21). `scripts/build_s2_raw_parcels.py` agrega las 10 bandas desde `DATA_S2/*.npy` de PASTIS-R.
2. **Las 3 vistas se alinean por `parcel_id` con inner join** — comparativa justa: mismo set de parcelas, mismos folds.
3. **Mismo spatial CV 5-fold para los 3 escenarios** — el delta de F1-macro refleja el dataset, no la particion.
4. **`train_time_s` = wall-clock del `fit` final** — el CA pide "tiempo de entrenamiento".
5. **El notebook se construye con `build_baseline_notebook.py`** (patron US-018) — reproducible, sin editar el `.ipynb` a mano. US-022 es el ultimo extend (§7-§8).
6. **`max_samples`/`shap_sample_size` parametrizados** — papermill en CI corre con valores reducidos (< 5 min); el notebook commiteado tiene los outputs del run completo.
7. **Export LaTeX via `to_pandas().to_latex()` encapsulado** — unico uso de pandas, aislado en `export_comparison_latex`.
8. **mIoU se mantiene como proxy** (jaccard macro a nivel parcela, heredado US-019 D6).
9. **US-022 integra, NO re-implementa** las secciones de US-019/020/021.
