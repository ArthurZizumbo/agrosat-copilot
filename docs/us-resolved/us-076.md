## Resumen ejecutivo

US-076 corre el protocolo few-shot transnacional REAL de EuroCropsML (LV->EE y LV+PT->EE; Francia NO
existe en EuroCropsML, el enunciado se corrigio) reusando el recipe XGBoost del baseline para producir
una **curva k-shot REAL** (F1-macro vs k) que mide el domain gap, alineada a HCAT v3 via el crosswalk de
US-074. La descarga real fue de **706,683 datapoints `.npz`** (EE 175,906 + LV 431,143 + PT 99,634, 4.15 GB)
desde Zenodo v11 (DOI 10.5281/zenodo.15095445) via un wrapper a la API REST (el `download_dataset` del
paquete es interactivo). La curva exportada tiene **63 filas con 63 valores F1 UNICOS** (3 escenarios x 7 k
x 3 seeds, cero hardcode), generada en vivo por `run_fewshot_curve` sobre los `.npz` reales. El notebook
quedo ejecutado por papermill (1 PNG + 4 HTML, 0 errores, `degraded=False`). La deuda DVC del subset crudo
que el manual-test del 2026-06-20 anoto como PENDIENTE quedo **RESUELTA** en la rama FINAL: el `.dvc` esta
commiteado. AlphaEarth-via-GEE queda FUTURE/anexo (EuroCropsML no trae AlphaEarth).

## Resultado del run (curva k-shot REAL, F1-macro media sobre 3 seeds, query set EE)

| escenario          | k=1   | k=5   | k=20  | k=100 | k=500 |
|--------------------|-------|-------|-------|-------|-------|
| LV->EE (pre-train) | 0.321 | 0.349 | 0.382 | 0.444 | **0.482** |
| LV+PT->EE          | 0.315 | 0.321 | 0.350 | 0.380 | 0.420 |
| sin-pretrain->EE   | 0.015 | 0.199 | 0.273 | 0.380 | **0.472** |

**Lectura del domain gap**: sin datos locales ni pre-train el modelo va perdido (F1=0.015 @k=1); el pre-train
en LV da arranque inmediato (0.32 @k=1) y mantiene ventaja hasta ~k=100, donde las muestras locales de EE
empiezan a cerrar la brecha (convergencia ~k=500). Espejo de la FORMA del paper @500 (pre-train-LV 0.66 >
sin-pretrain 0.57; aqui 0.482 > 0.472, recipe XGB tabular vs red temporal del paper). Es domain gap MEDIDO,
NO un claim zero-shot.

## Decisiones tecnicas clave + caveats

- **Francia NO esta en EuroCropsML** (solo EE/LV/PT). El enunciado "Francia->Estonia" se corrigio a LV->EE / LV+PT->EE
  (arXiv 2407.17458, Tabla II).
- **EuroCropsML NO trae AlphaEarth**: el feature vector se deriva de la serie S2 propia del dataset (mean/std/
  min/max/range/last-first/slope por banda + percentiles {10,25,50,75,90} = 156 dims, fija independiente de T).
  AlphaEarth-via-GEE en los centroides queda **FUTURE/anexo** (no bloquea la curva).
- **`download_dataset` del paquete es interactivo** (`select_version` con `input()`); por eso se implementa
  `download_eurocropsml` que pega a la API REST de Zenodo, selecciona la version valida mas reciente de forma
  determinista (misma blocklist que `select_version`) y stream-descarga solo `split.zip` + `preprocess.zip`
  (`raw_data.zip` 3.28 GB OMITIDO). Version efectiva v11 (DOI 10.5281/zenodo.15095445).
- **Pre-train = source folded en la matriz de fit** (XGB no tiene warm fine-tune). La curva XGB es referencia de
  FORMA del paper, no de valor absoluto.
