## Resumen ejecutivo

US-075 entrega la ingestion de un subset real de Sen4AgriNet (Catalonia + Francia), un adapter
netCDF -> tensor `(T,10,128,128)` compatible con el dataloader denso PASTIS-R, el finetune denso
FR->Catalonia en H100, y el **Delta mIoU zero-shot vs few-shot** = medida cuantitativa del domain gap
Franco-Iberico. El resultado REAL (H100, 20-jun-2026, datos reales, regla cero-sinteticos): zero-shot
**mIoU=0.0000** (el TSViT-pheno PASTIS-Francia proyectado 18->macro colapsa sobre Catalonia: gap
catastrofico, no un bug) y few-shot **mIoU=0.2468** (head macro finetuneado con k=10 parches), para un
**Delta mIoU = +0.2468** (best epoch 30, 40 epocas en 76.8 s). El Delta ES el entregable cientifico
(medir el gap), no un accuracy alto — alineado con el caveat AC-5. El notebook quedo ejecutado por
papermill end-to-end en la VM H100 con 2 figuras PNG y 0 errores. Cierra con dos deudas de versionado
HONESTAS (no de resultado): el lineage MLflow quedo en fallback `file:./mlruns` (server :5010 caido en
la VM) y el checkpoint `best.pt` + el subset `.nc` viven solo en la VM F: (no replicados a local).

## Decisiones tecnicas clave + caveats

- **El zero-shot 0.0 es REAL, no un bug**: el modelo FR proyectado 18->macro colapsa sobre Catalonia a
  `grassland`+`vegetables` (support ~0 en el GT ES, dominado por cereals/legumes). Diagonal de la matriz de
  confusion = 0 -> mIoU exacto 0.0. Gap de dominio Franco-Iberico catastrofico, consistente con AC-5.
  Documentado en `docs/blockers/epic12-vm-setup.md` B4.
- **El notebook NO reentrena**: re-corre el adapter + inferencia zero-shot sobre los `.nc` reales (60 tiles,
  mIoU=0.0000) y lee el JSON autoritativo del finetune para el headline Delta. Sincronizados notebook + JSON.
- **Correccion al plan §3.1**: `allow_patterns=["cat_2019/*",...]` NO funciona (`cat_2019` etc. son configs del
  builder, no rutas). Layout real `data/<year>/<TILE>/...nc`. Detalle en blocker B3.
- **Delta modesto en valor absoluto, pero ESE Delta es el entregable cientifico** (medir el gap), no un
  accuracy alto — alineado con el caveat AC-5 (AlphaEarth transferibilidad espacial limitada).

## Pendientes / fuera de alcance (deuda de versionado HONESTA, no de resultado)

- **AC-6 lineage MLflow en fallback `file:./mlruns`**: el server Docker :5010 estaba CAIDO en la VM al
  momento del run, por lo que `track_experiment` escribio el run con tags `data_version`/`code_version` al
  store local `file:./mlruns` de la VM, NO al server Docker centralizado. Cuando el server vuelva habria que
  re-sincronizar o re-loggear el run. No compromete la validez cientifica (el Delta y el checkpoint son reales).
- **Checkpoint `best.pt` solo en VM F:**: `checkpoints/segmentation/tsvit-pheno-sen4agri-cat-ft-v1/best.pt`
  NO esta replicado a local. El resultado (Delta +0.2468) esta capturado en el JSON committed; el peso del
  finetune queda como deuda de replicacion.
- **Subset `.nc` (943 MB) en VM, no replicado a local**: versionado por DVC (`data/sen4agrinet.dvc`, 88 files)
  pero los `.nc` viven en la VM F: (no en cache local). Por eso 4 tests del adapter quedan `skipped` en local
  (skips legitimos: los `.nc` nunca van a Git). En la VM son 11 passed.
- **U-TAE secundario** (`utae-isaac/best_model.pt`) quedo como opcion no ejercida; el finetune principal fue TSViT-pheno.
