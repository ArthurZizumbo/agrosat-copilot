## Resumen ejecutivo

US-022-b nacio para evitar mezclar trabajo nuevo con el cierre del Avance 3
(US-022 baseline tabular). Cuatro objetivos:

1. **Infra GCP L4 de entrenamiento** (`ml-train` Dockerfile + Terraform SAs +
   Cloud Run MLflow scale-to-zero + bucket `agrosat-artifacts-${env}`).
2. **Saldar la deuda FarSLIP Fase 4** (US-017 AC-3/4/6/8) — pasa a `us-022-c` P1
   por decision del usuario 2026-05-23 (correr en GCP dedicada por exactitud).
3. **Reencuadre fenologico** (ADR-006): ablation de features con descarte de
   `geom_*` + ERA5 + SRTM, modelos temporales TempCNN/InceptionTime portados
   nativos, clustering sin coordenadas (feedback Dr. Camacho), notebook
   entregable `05_reencuadre_fenologico.ipynb`.
4. **Rama semantica fenologica** (Wen et al. 2025): generador Gemini 3.5 Flash
   + text-encoder sentence-transformers + bloque `pheno_text_*` en `fusion.py`.

La US cierra con el codigo + tests + infra listos y dos resultados clave
validados:

- **Hipotesis C-2 (Dr. Camacho) confirmada empiricamente**: descartar las
  3 columnas `geom_*` NO degrada F1-macro (delta = 0.0). El modelo aprende
  fenologia, no geografia. Lo mismo aplica al quitar adicionalmente ERA5+SRTM
  (delta = 0.0), confirmando que AlphaEarth ya codifica clima/topografia
  internamente. Es el resultado central del reencuadre.
- **Hipotesis C-4 (supera baseline 0.32) pasada en gate minimo**: XGBoost
  sobre el conjunto ganador `full`/`no_geom`/`no_geom_no_era5_srtm` obtiene
  F1-macro **0.4094 (+0.089 sobre el baseline 0.32)**. El target deseable era
  ≥ 0.45; queda corto pero supera el gate minimo.

El smoke del notebook 05 se ejecuto el 2026-05-23 (modo degradado: 800
parcelas, 2 epochs CPU, 24/24 cells, 7 PNG embebidos, 0 errores). El run FULL
CUDA con los 4 fixes ML (class_weights, weighted_sampler, lr_scheduler,
early_stopping) queda en [`us-022-c`](../product-backlog/us-022-c-cierre-fenologico-farslip-dvc.md)
P3 para reemplazar los outputs del smoke con los del dataset completo
(85.951 parcelas).
